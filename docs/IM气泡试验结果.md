## 实现与边界

`009-5-patch-im.js` 将当前身份 ID 传给已有 MessageRow，以 ID 判定本人消息。消息类型只用于选择展示样式；原 TextContent、MarkdownContent、文件卡、事件处理继续复用。

`017-im-shell.css` 实现右侧浅蓝/左侧浅灰、短消息收缩、连续消息对齐和宽内容内部滚动。文件卡不重复套文字气泡。头像、AI 标、时间、输入框、导航和个人 Eva 页面沿用现行实现。

`009-3-data-im.js` 提供测试群内容；`009-2-membership.js` 沿用成员存储的一次性增量初始化，创建 prod 项目下的群和三个子区。复用现有成员与项目管家，不另建项目、人员或后台存储；刷新不重复灌入，删除后不重建。

未修改任何后端源码、API 请求、协议、Markdown 解析/净化逻辑或消息传输结构。原型业务使用浏览器本地数据；没有用真实服务器验证端到端兼容。
