# IM 界面一致性

2026-09-09 用户确认从 Eva Evolve 定向同步。来源：a742215931ee8561e129a5b2d209515dd2204465，老版基线：df33b61。

- 关注、最近、项目内群聊与我的 AI 复用统一 IM 主题适配层。提及、选中强调使用 Eva 蓝色，普通悬停保持中性灰；项目配色、头像及代码语法配色保持各自语义。
- 普通未读数使用浅灰圆角徽标，16px 高、至少 18px 宽、5px 圆角；@我使用蓝色文字。紧凑树形列表为展开箭头保留固定列，最近列表保持摘要和紧凑时间，不新增箭头。
- 聊天任务、子区、聊天信息及子区信息共用 56px 标题栏、20px 左右内边距和右侧关闭入口。子区使用覆盖方式，不压缩原消息区。
- 聊天文件预览作为消息主内容的右侧并排兄弟区域打开，并挤压消息主内容，不使用蒙层或覆盖布局；保留阅读所需宽度和业务工具。预览左边缘可拖拽并支持键盘调整宽度，双击或按 `Home` 恢复默认宽度。任务详情本身继续覆盖聊天区，任务缺失状态同样提供右侧关闭；任务详情内的文件预览再从详情右侧并排推出并挤压详情内容。预览头部右侧统一提供全屏按钮，全屏仅覆盖系统标题栏下方工作区；`Esc` 优先退出全屏，再次按下才关闭预览，退出后恢复原侧栏宽度。
- 同类新增入口复用 Lucide Plus。提交、保存、取消等表单按钮不因本规范强制加图标。
- 新建项目主按钮默认蓝色，悬停使用主色加深变量，保持白色文字；不能回退灰色禁用外观。
- 不改变会话权限、消息内容、任务数据与个人 Eva 布局。稀疏未读提示只影响初始项目演示标记，不清除浏览器保存的用户状态。

实现复用现有 IM 补丁、样式及语义变量。新增入口需检查两个消息入口、打开/切换/关闭面板、草稿和滚动位置；不得复制独立业务组件。

聊天区元素的暗色取值、交互态映射与验收方法见 [IM 暗色适配规范](IM暗色适配规范.md)。IM 内核消费 `--wk-*` / `--semi-*` 命名空间，不随 Eva 语义 token 自动进入暗色，新增或修改聊天区元素时必须按该文补齐暗色映射。
