# Tooltip 系统治理清单

## 已确认的原因

2026-10-15 核对 plane-gantt 工作稿源码，以及会话《排查 Tooltip 常亮原因》（01a11ff1-5b5e-7952-afbb-04f0118ca739）。历史报告仅用于定位，不能代替当前版本验证。

DOM 本身不是问题。反复故障来自三条路径：程序恢复焦点被当成主动打开提示；按钮被整块重建后丢失关闭状态；React 元素通过外部 DOM 适配层接提示，节点和提示分属不同生命周期。

## 已实施，待用户验收合并

- 公共 restoreFocus 同步边界，接入共享任务抽屉、Modal、Popover、聊天侧栏和显式返回入口。
- 移除按 Modal 和群聊按钮 class 猜测恢复意图的特例；保留正常焦点返回及键盘可见提示。
- Tooltip 生命周期与甘特图焦点返回回归加入 `npm run test:tooltip` 和 CI。
- 公共恢复边界补充同步事件、嵌套调用、异常清理及失效入口测试。

## 尚未完成的结构迁移

| 区域 | 当前源码证据 | 迁移边界与保留行为 |
| --- | --- | --- |
| 个人 Eva 侧栏 | `052-personal-eva-gds.js` 的 renderRail 仍用 outerHTML 整块替换 | 改为稳定的 React 子树，同步删除对应字符串模板和事件委托；保留分组、置顶顺序、折叠、菜单、草稿、滚动和外观 |
| 任务标题 | `062-loop-table-view.js`、`062-loop-gantt-view.js` 仍用 data-eva-tooltip 做截断提示 | 公共 React 截断提示直接持有触发节点；保留实际截断判定、点击、拖动及统一详情 |
| 文件库按钮 | `063-file-controls.jsx` 的置顶和全屏仍用兼容属性 | 同一 React 组件拥有按钮和提示；保留权限、置顶、全屏和返回位置 |
| IM、成员等 React 入口 | `009-5-patch-im.js`、`009-2-members-ui.js` 等仍有兼容标记 | 按具体组件迁移，不按文件名批量替换；保留身份、权限、菜单层级及共享模板 |

这些是源码确认的接入风险，不表示每个入口都已复现故障。历史会话中的文件库问题仍需在当前版本复现。

## 实施与验收边界

优先建立公共 React 截断及操作提示，再迁移任务、文件库；个人侧栏作为独立完整区域迁移。每批删掉旧接入和特例，不叠加两套控制器。兼容层仅服务尚未迁移的原生 DOM 区域，新 React 入口不再新增兼容属性。

每批覆盖悬停、移出、点击、菜单、文案变化、节点替换与卸载、路由往返、鼠标与键盘关闭、重新 Tab、输入法及嵌套 Escape。用户验收后才能合并 main。公共焦点修复通过不代表结构迁移完成，也不代表整站通过 WCAG 审核。
