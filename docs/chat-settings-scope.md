# 聊天信息管理：本轮范围

参考 Octo-Web c2e2aee 的 ChannelSetting、channelSettingMemberSection、ChannelSettingRows，按 Eva 已确认的成员权限适配。这是本地原型，不连接 Octo 生产服务。

保留群聊成员网格、全部成员、添加/移除/转让/退出/解散及已确认权限规则、群名/头像/公告；私聊保留对象信息；两类共用免打扰、置顶与清空记录。全员群仍与项目同步。

Octo-Web 是团队 IM 交互参考，不是 Eva 的功能清单；只接入 Eva 已确认且当前原型支持的能力。

项目和群聊直接添加成员，无审批或被添加人接受机制；不提供邀请记录、待处理信箱或左上角信箱按钮。被添加时不自动带入分身，分身仍由主人自行添加。

GROUP.md、Webhook 保留现状，不因群聊管理重做删除、扩展或重写。群成员列表承担管理员与 AI 管理员任免（行内二合一操作），群聊管理仅保留转让群主；项目权限不自动继承为群管理员（2026-09-24 确认）。群聊管理沿用确认稿的角色标签，其他身份入口仍遵循 AGENTS.md 的 AI 身份统一规则。群级 Bot 免 @ 设置已于 2026-09-24 下线，免 @ 只保留 Bot 级、由分身主人在资料卡「免 @ 回答」按群开启，仅保存原型配置，实际触发及 Bot 自主治理尚未接入，不得描述为已接通。

打开信息面板不重建聊天流或输入框，保留草稿和滚动位置，不覆盖系统标题栏。

不纳入二维码/扫码、Webhook、保存到通讯录或「保存的群聊」、私聊内发起群聊、群备注和群内昵称；不保留空占位或模拟成功提示。Eva 通讯录保持独立维护。

## Edge 验收

1. 打开 http://127.0.0.1:4174/#/messages ，默认王宜林。选择供应商整改协同，打开右上角三个点。
2. 检查功能范围，点加号查看共同选人模板。空选不能确认，自己的分身可独立多选。
3. 修改公告并保存，关闭重开、刷新后应保留。
4. 切到何静私聊，打开三个点，仅有对象信息和三项共用设置。
5. 输入未发送草稿，反复开关面板，确认草稿保留；群聊、私聊往返不残留上一会话的设置。

当前未合并 main、未部署。

## 协作说明编辑界面

GROUP.md 在产品界面统一称为「协作说明」，群与子区共用同一个编辑器。辅助说明为「供成员了解本群的协作背景，也为 AI 提供上下文。」；子区使用「本子区」。

不提供编辑／预览切换：有编辑权限直接显示 Semi TextArea，只读成员直接查看 Markdown 渲染结果，操作使用公共 Button，辅助信息使用 Typography 和公共字体参数。正文采用 Eva 主表面与正文比例字体；仅编辑者显示字数，位于编辑区下方；底部仅保留保存操作，不显示版本号、独立删除或分隔线，不重画原生控件。

占位提示仅为「填写协作目标、规则和重要资料…」。尚未填写（内容为空、版本为 0）且有编辑权限时，打开自动将目标、协作规则、重要资料三段引导初始化为可编辑草稿，不自动保存、不提供插入模板按钮。已有内容和已保存的空内容不覆盖；编辑过程中清空不自动补回。关闭丢弃未保存内容。只读成员不会看到未保存的模板。

界面显示「已输入 N 字」，按 Unicode 字素计数，不含空白与换行；底层仍按 UTF-8 字节执行原 10 KB 上限，不把字节上限伪装成字数上限。

清空正文后点击保存即保存为空；即使首次打开后清空模板，也允许保存空内容。已保存的空内容重新打开或刷新后保持为空，不再初始化模板。保存成功提示「已保存」，内容未改变时禁用保存。返回或关闭放弃未保存修改；只读成员只阅读已保存内容，不显示编辑按钮、字数或模板。

权限、只读 Markdown 渲染、10240 UTF-8 字节上限保持原合同；内部版本仅用于已保存状态兼容，不向用户展示，不保留独立删除接口。群与子区内容独立保存。原型继续使用浏览器本地状态，未接入 Octo 服务或真实 AI 上下文注入。
