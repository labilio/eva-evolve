# EvaMate 0.3.0 质量门禁

页面同时通过自动检查和人工检查后才可交付。自动检查不能代替视觉判断，截图相似也不能代替结构与无障碍。

## 自动检查

在规范包目录运行：

```bash
node validate.mjs
```

项目代码建议增加以下规则：

- 扫描业务 CSS/JS/TS/JSX/Vue/Svelte，禁止新增十六进制、rgb/rgba/hsl 颜色；令牌定义文件除外。
- 检查所有 `--evamate-color-*` 引用在 `tokens.css` 中存在。
- 检查根主题只允许 `light` 或 `dark`。
- 对主要页面执行 1200 × 800、1024 × 768 与窄视口截图回归。
- 用 axe 或等价工具检查名称、角色、焦点与颜色对比度。

## 人工视觉门禁

### 页面骨架

- [ ] 已明确使用 `standard-workspace` 或 `editor-workspace`。
- [ ] 1200 × 800 基准态的主分栏和内容列在 1 px 容差内。
- [ ] 窄视口通过折叠/抽屉/重排适配，没有整体缩放。
- [ ] 标题先截断，右侧操作不被压缩或遮挡。
- [ ] 滚动区域和固定区域边界清晰，焦点环没有被裁切。

### 颜色与主题

- [ ] 所有产品颜色来自 Semantic Variables。
- [ ] Light 与 Dark 使用同一 DOM 和同名语义角色。
- [ ] 图片与插画没有被自动反相。
- [ ] 同一区域只有一个强蓝主行动。
- [ ] 反馈状态不仅依赖颜色。

### 字体与内容

- [ ] 中文 UI 使用 PingFang SC 及规定回退。
- [ ] Hero 32/40/600，一个页面最多一个。
- [ ] Praise 只用于品牌装饰文字。
- [ ] 正文、标签和元信息使用 `styles.json` 中的文字样式。
- [ ] 文案在真实长文本、空数据和本地化场景下不重叠。

### 间距、圆角与效果

- [ ] 主要几何来自 Dimension Variables。
- [ ] 相关内容使用紧间距，区块之间使用更大间距。
- [ ] 圆角表达层级，外层半径不小于内层半径。
- [ ] 当前主题只加载对应 Light/Dark elevation。
- [ ] Glass blur 只用于浮层或导航，不用于正文区。

### 图标与交互

- [ ] 图标来自同一圆角线性家族与 24 × 24 源网格。
- [ ] 没有 emoji、Unicode 箭头或彩色实心图标。
- [ ] 图标按钮有可访问名称和不少于 32 px 的常规桌面命中区；关键操作 SHOULD 达到 40 px。
- [ ] hover、pressed、focus-visible、disabled 均可辨认。
- [ ] 所有操作可由键盘完成，浮层焦点可进入并正确返回。
- [ ] `prefers-reduced-motion` 下无非必要位移动画。
