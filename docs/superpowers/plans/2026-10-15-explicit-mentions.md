# 显式提及实施计划

目标：新消息仅把明确选择的对象作为提及；手打/纯文本粘贴同名内容无提及语义。
架构：共享编辑器提取带位置的对象，消息 store 保存并校验，统一渲染按位置识别；草稿元信息按现有账号/会话记忆保存并核对正文，禁止凭姓名恢复。

- [x] 提及位置合同与数据层测试：普通文字、选中对象、重复同名、批量对象、当前成员校验。
- [x] 贯通共享编辑器、主流/子区发送、草稿与纯文本粘贴；保留头像提及和回复的明确对象操作。
- [x] 通知、隐藏会话恢复和 AI 原型回执只读结构化对象；个人 AI 单聊保持直接发送。
- [x] 历史预置消息兼容与新版消息严格隔离；Edge 输入/发送/往返/刷新及亮暗回归。
- [x] 审查完整链路并交付本地验收，不合并 main。
