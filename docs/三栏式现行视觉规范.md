## 2026-09-15 导航选中表面以 EvaMate 0.3.0 为准（裁决两套规范冲突）

两套现行规范对选中态取值直接冲突：Eva GDS for AI 2.0 §7.2 要求白底 + `#DBDBDB` 中性描边；EvaMate Design System 0.3.0 要求 `color/surface/selected = blue/50 (#EBF3FF)`，强选中时再加 `border/selected = blue/600 (#1563EB)`。

用户 2026-09-15 明确裁决：**以 EvaMate 0.3.0 为准，采用浅蓝选中表面。** 据此：

- 浅色选中底色取 EvaMate 精确 token 值 `#EBF3FF`（原为 `#dce9ff`，与 EvaMate token 差 1–2 个通道，属「看起来差不多但不是同一个值」，一并校正）。

暗色下的选中表面**未**采用 EvaMate 的 `blue/700 (#0F50C7)`：该值需要配套的前景色取值，而 AGENTS.md 记录两套规范的明暗主题分工尚未逐条划定。暗色维持 `#1e3a63`，但修正其前景色缺陷：原配 `#1563EB` 文字对比度仅 2.18，严重不达标；按 GDS §3.4「链接/图标/焦点环提亮到 `#93B5FF`」把 `--eva-nav-accent` 在暗色下提亮，对比度升至 5.59 达标。
