# Eva 同学：产品规则

版本：v0.1，2026-09-15。

- 个人 Eva 同学主入口只有一个固定 Eva，不提供多助理选择、创建或编辑。个人助理的创建与编辑归[我的 AI](./我的AI.md)。
- 文件夹只组织个人对话，不等同于协作项目、AI 身份或电脑目录，不产生额外授权关系。
- “默认”也是完整分类，不能重复创建、重命名或删除，可以置顶。删除普通文件夹保留其中对话，并移回默认分类。
- 对话改名或移动不改变稳定身份与历史内容。
- 个人会话和团队 IM 会话独立；个人历史、草稿不因连接同一助理自动导入团队。
- 同一执行端不代表共享全部上下文或历史，也不构成合并两个入口的理由。
- 头像与 AI 标按[通用 AI 身份规则](../通用规范/人类与AI身份展示规范.md)处理。

## 边界

旧规范中“把团队助理收敛成同一个 Eva”的历史数据迁移，不作为取消“我的 AI”多个个人助理的依据；生产历史迁移策略尚未确认。本规则不把浏览器本地存储方式规定为正式产品存储方案。
