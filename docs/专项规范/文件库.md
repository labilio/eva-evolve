# 文件库：归属与共享边界

版本：v0.1 提炼稿，2026-09-15。来源文档标为“原型方案 V8”；以下为方案中可独立表达的产品边界，正式研发采用前仍须确认方案基线，不能理解为本轮重新批准了全部文件权限。

## 已有方案中的边界

- 个人文件库归个人，项目文件库归具体项目；“我的项目”的团队文件与一级文件库中的同一项目库共用文件 ID、目录及权限结果。
- Owner 指文件库角色，不是每个文件额外设置的所有者。上传者、保存者、AI 或任务执行人不因产生文件获得额外管理权限。
- 会话附件默认留在来源会话，用户保存后才成为目标库中的独立文件；项目任务产出自动写入所属项目库，是另一个产生流程。
- 保存会话文件须同时满足来源可读、目标可写；结果继承目标文件库权限，不扩大来源群或任务权限。
- 已保存文件与来源会话附件独立删除。系统关联用于追溯，不是访问凭证；无来源权限时不能通过关联泄露信息。
- 快捷方式只引用源文件，不复制、不扩大源权限；创建须源可读、目标可写，使用时继续检查源权限。删除快捷方式不删除源文件。
- 外部链接和外部文件夹只是原平台入口，Eva 的权限不绕过原平台鉴权，不把链接当作已经同步的文件内容。
- 置顶是当前账号偏好，不改变归属或权限。项目成员退出后失去项目文件访问权。
