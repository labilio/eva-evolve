# 通讯录：产品规则

版本：v0.1，2026-09-15。

- 通讯录是组织内已激活 Eva 用户账号的目录，不是某个项目或群的成员表，也不以演示人员白名单限定。
- 每位联系人对应零或一个分身；名称、头像和 AI 标引用[联系人与 AI 身份展示规范](../通用规范/联系人与AI身份展示规范.md)。无分身表示未创建，不伪造默认分身。
- 目录可见不代表加入项目或群，不授予其消息、文件或任务的访问权。
- 通讯录不增加项目／群的成员管理、添加入群或角色管理职责。
- 人员资料使用稳定身份 ID；没有来源的部门、职位等资料不编造。
- 历史作者资料可供历史内容解析，但读取旧档案不恢复账号资格或成员权限，也不自动把历史作者加入项目或群。
