- 个人文件夹、对话、折叠状态由 `EvaPersonal` 数据仓唯一管理，浏览器 localStorage 保存。它不提供云端同步。界面通过稳定 ID 读取详情；路由决定已选对话。中栏动作仅更新中栏，不重建右侧输入和消息。
- 新建上下文与各历史会话的草稿按 ID 隔离，离开组件时保存内存草稿；刷新恢复已发送消息与分类，不宣称草稿跨刷新持久化。
- 「我的 Agent」中的个人助理新建与编辑共用完整编辑弹窗和同一份助理配置数据；不导入个人 Eva 的本地聊天历史或草稿。
- 个人首页的居中欢迎、输入、技能及任务生命周期继续使用现行 GDS；取消右侧助理选择，显示当前文件夹，可通过下拉选择默认或已有文件夹，切换时保留正在输入的内容。团队消息和「我的 AI」布局不受此规范限制；「我的 AI」以横线分隔 AI 小队列表与按角色分组的 AI 单聊。
