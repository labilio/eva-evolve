# 个人 Eva：单助理与文件夹

- 顶部固定“新对话”，新对话默认归入“默认”；文件夹行内的加号在该文件夹内发起对话。首次发送时才保存对话。

- 文件夹只组织个人对话，不等同于 AI 身份、团队协作项目或电脑目录；示例文件夹沿用“供应链运营协同”名称，无额外项目实体或授权关系。
- 对话可重命名、移入其他文件夹或移回默认；保持稳定 ID 与历史内容。每组超过六条时提供展开／收起。
- 所有个人对话展示 Eva 同学；历史的五条对话均保留原 ID。团队 IM 仍使用独立数据仓与会话，团队侧也按用户追加确认收敛为同一个 Eva；旧助理的团队会话保持稳定 ID、内容、置顶和草稿。其他助理未发送的新会话草稿转为独立待发送会话，避免覆盖 Eva 的草稿。云端分身和数字员工保留各自身份；原来同步自已撤销助理的分身保留配置并转为独立来源。
- 个人文件夹、对话、折叠状态由 `EvaPersonal` 数据仓唯一管理，浏览器 localStorage 保存。它不提供云端同步。界面通过稳定 ID 读取详情；路由决定已选对话。中栏动作仅更新中栏，不重建右侧输入和消息。
- 新建上下文与各历史会话的草稿按 ID 隔离，离开组件时保存内存草稿；刷新恢复已发送消息与分类，不宣称草稿跨刷新持久化。
