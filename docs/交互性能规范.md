# 交互性能与数据读取

适用于现有 Eva 模块的切换、选择、搜索和弹窗。性能优化必须保留权限、消息、身份与状态归属；不得用延迟显示或动画遮掩同步阻塞。

## 实现约束

- 当前账号使用 `actorId()`。项目读取使用 `projectRecord(id)` / `projectRecords()`，分身目录使用 `cloneRecords()`，混合身份候选使用 `identityRecords()`。这些接口返回隔离副本；不得为了读取少量元数据复制包含聊天记录的全量 `snapshot()`。
- 全量快照用于明确需要整份状态的事务、导出或恢复。新增 UI 读取应先确定最小数据范围，不能默认选择全量快照。
- 选中项、搜索文本、弹窗开关与列表业务数据分别建模。只切换选中项，不应重算无关会话的历史消息、目录身份或全部业务域统计。
- 派生列表按真实数据版本更新。缓存依赖必须涵盖账号、数据版本、来源和相关入口模式；不得把每次 render 新建的数组或对象作为唯一数据版本。
- 权限判断读取当前成员数据，不缓存授权结果。项目/身份/文件数据变化时，相关派生结果立即失效；验证退出项目、成员移除、改名和新消息更新。
- 不使用全局 MutationObserver、轮询、点击拦截或延迟定时器维护第二份选中状态。对低成本计算无需滥加缓存。

## 验证

- 测量点击到绘制，并同时记录重复读取和计算次数；自动化驱动总耗时与页面绘制时间分别报告。
- 性能回归优先验证业务事实：切换当前会话不读取无关群的消息；文件权限查询不复制聊天；修改数据后列表及时更新。机器耗时用于对比，不以脆弱的绝对毫秒阈值代替行为断言。
- 护栏：`tests/ui-data-read-contract.test.mjs`、`tests/browser/im-switch-performance.mjs`、项目文件与通讯录的定向读取测试。
- 按 CONTRIBUTING.md 执行受影响模块的浏览器往返验收，不因性能优化删减功能或弱化原有测试。
