# 任务看板卡片展示逻辑

本文汇总项目「任务 → 看板」的当前展示实现，供产品评审和后续维护使用。范围包括字段位置、显示条件、空间不足时的处理和列表滚动；不讨论拖拽、未读提示、编辑或任务执行流程。

核对日期：2026-10-15。依据本地源码基线 `967684d`；以下尺寸为 CSS 像素，不按截图缩放后的像素计算。本文记录现状，不新增界面规则。

## 1. 看板与状态列

- 每个任务按自身状态进入对应列。父任务和子任务都使用同规格独立卡片，不嵌套、不缩进，也不显示父任务编号、子任务进度或展开按钮。
- 当前状态顺序为：待规划、待办、进行中、审核中、已完成、受阻、已取消。全部状态列保留，空列不隐藏。
- 列头从左到右为状态图形、状态名称、该列任务数量，最右侧为新建加号。数量取当前传入看板的任务集合中该状态的总数，筛选会影响数量，分批加载不会使它变成“已加载数”。
- 列内优先按任务 `position` 升序排列；相同位置保留输入顺序，缺少有效位置的任务排在有效位置之后。
- 列宽为 296px，列间距为 16px。窗口放不下所有列时，看板横向滚动，不把列压成窄卡片或换到下一排。
- 每列的卡片区独立纵向滚动，列头在卡片滚动区外。列头名称单行省略，状态图形、数量和加号不收缩。

## 2. 单张卡片布局

卡片分为顶部信息行、标题区、底部信息行。

| 区域 | 内容与顺序 | 显示条件 |
| --- | --- | --- |
| 顶部左侧 | 优先级图形 → 完整任务编号，如 `SC-104` | 当前配置开启这两个字段；优先级用图形表达，编号带项目前缀 |
| 顶部附加信息 | 运行中标记 | 仅组件收到该任务的运行中状态时显示；不由“进行中”列名推导 |
| 顶部右侧 | 截止日期或逾期天数 | 仅任务设置 `due_date` 时显示 |
| 中间 | 任务标题 | 独立成区，最多两行 |
| 底部左侧 | 标签，最多前两个，再接 `+N` | 有标签时显示，无标签时不显示占位文案 |
| 底部右侧 | 负责人头像＋姓名 | 有负责人时显示；没有负责人时显示“未指派” |

卡片不重复显示所在列的状态图形，不显示创建时间、更新时间、项目名称、任务描述、附件、角色或父子关系信息。底部身份取负责人 `assignee_*`，不是来源者或创建者。

字段由 `EVA_BOARD_CARD_DISPLAY` 集中配置，当前没有面向用户的字段自定义入口。

## 3. 标题与卡片高度

- 标题使用 14px 字号、22px 行高、500 字重；编号、日期和负责人使用 12px 字号、16px 行高。
- 短标题只占一行，不强制预留第二行。长标题可换成两行，超过两行截断并显示省略号。
- 连续英文、物料编码等没有自然分词的位置也允许断行（`overflow-wrap: anywhere`），避免撑宽卡片。
- 标题节点带完整文本的原生 `title`，可悬停查看；卡片详情仍保留完整标题。
- 卡片没有统一固定高度，随标题实际占用的一行或两行增高；同列卡片纵向依次排列，相邻列不按行对齐。
- 卡片内边距 12px，三个区域之间间距 10px，相邻卡片间距 8px。圆角、表面、边框等读取现有主题 token；普通态无阴影，悬停时边框增强并出现轻微描边阴影。

## 4. 截止日期

| 数据情况 | 右上角显示 |
| --- | --- |
| 没有截止日期 | 不显示日期，也不显示“未设置” |
| 有日期且未逾期 | `截止 MM-DD`，次级文字色 |
| 已逾期且任务未完成、未取消 | `逾期 N 天`，危险色 |
| 已完成或已取消且有日期 | 仍显示 `截止 MM-DD`，不显示逾期警示 |

日期只读取任务的 `due_date`；逾期按公共日期工具判断，不拿创建或更新时间替代。悬停日期可查看带年份的完整截止日期。

日期保持单行、不收缩，并通过自动左外边距贴右。顶部空间不足时，任务编号可以收缩为单行省略号；优先级图形不收缩。当前没有针对全部顶部字段同时超宽的二级折叠菜单或换行方案。

## 5. 标签与负责人如何分配空间

底部始终保持同一行：标签靠左，负责人靠右，二者间距 8px。不会因为空间不足把负责人移到下一行。

### 标签数量与长标签

- 按标签数组原顺序显示前两个标签；超过两个时，追加 `+N`，其中 N 是总数减二。例如 3 个标签显示前两个和 `+1`，5 个显示前两个和 `+3`。
- `+N` 按数量计算，不测量实际剩余宽度。即使前两个标签已经被压缩，N 仍然只计算第三个起的标签。
- 标签区可收缩，标签不换行；单个标签放不下时单行省略。`+N` 本身不收缩，外层标签区仍受可用宽度限制并裁切溢出。
- 标签使用统一中性浅底、无描边、常规字重，不按标签数据中的颜色分别着色。
- 当前标签及 `+N` 没有独立的悬停完整列表或展开浮层。需要完整内容时进入任务详情。

### 负责人

- 头像整体尺寸为 16px，与姓名间隔 6px；姓名单行显示，放不下时省略。
- 没有负责人时只显示“未指派”，不显示虚构头像；有负责人 ID 但缺少姓名时回退为“未命名”。
- 负责人节点带原生 `title`，内容为“负责人：姓名”或“负责人：未指派”。
- 无标签时，负责人仍靠右；有标签时，标签区和负责人区共同参与弹性收缩，当前没有固定的左右宽度比例，也没有“姓名始终完整、标签全部让位”的保证。
- 身份渲染复用公共头像组件；兼容数据若为 AI 身份，组件还会附公共 AI 标。这不改变现行负责人候选范围。

## 6. 任务较多时

- 每列首次最多加载 30 张卡片。接近列底部（剩余距离小于 240px）时再加载最多 30 张，也提供“加载更多任务”入口。
- 已加载数量超过 30 时，使用可见窗口渲染：只挂载视口附近的卡片，上下额外保留各 5 张缓冲，其余用占位高度维持滚动范围。
- 卡片实际高度会被测量，用于计算窗口与占位；代码中的 140px 是未测量时的估计高度，不是卡片固定高度。
- 列滚动位置和加载数量按项目及状态记忆，在同一页面生命周期内切换视图后恢复；这里不承诺刷新或跨设备恢复。
