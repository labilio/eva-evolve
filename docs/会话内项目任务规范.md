# 会话内项目任务规范

本规范适用于团队 IM 中的任务入口、后续消息转任务入口及其创建流程。依据本轮已确认的产品定义：**这里的任务只指所属项目的 Loop 任务**。它不是个人待办、自动化任务，也不是某次 AI session 的执行记录。

## 1. 入口与适用范围

| 会话类型 | 项目任务入口 | 任务归属 |
| --- | --- | --- |
| 项目全员群 | 有权限时显示 | 当前项目 |
| 项目内普通群 | 有权限时显示 | 群所属项目 |
| 项目群的子区 | 有权限时显示 | 子区所在群的项目 |
| 非项目群及其子区 | 不显示 | 无 |
| 人与人私聊 | 不显示 | 无，即使双方同属项目 |
| 人与分身、数字员工的私聊 | 不显示 | 无，即使该 AI 加入了项目 |
| 我的 AI 的 OpenClaw session | 不显示 | 无 |
| 个人 Eva 会话 | 不显示此入口 | 不适用 |

不得根据名称、聊天内容提到的项目、上一次打开的项目或 AI 的归属猜测任务项目。子区先解析父群，再通过成员体系的稳定 ID 获取项目。当前供应链演示关联：协作项目 `prod`，任务看板项目 `p-supply`；二者是适配关系，不得复制项目。

## 2. 当前交互与后续边界

当前实现：会话右上角“创建任务” → 在当前会话上打开统一 Loop 创建弹窗 → 确认提交 → 关闭弹窗并显示完整任务编号。不得跳转项目页替代创建入口。

所属项目由当前群/子区解析并传入表单，不依赖上一次打开的项目。提交时再次校验群及项目权限。创建后保留当前会话；任务进入所属项目看板。当前没有自动发送聊天任务卡片，不能把提示成功说成已发送任务卡片。

后续若加入“将消息转为任务”，必须继续复用同一创建组件和数据入口；消息只能预填上下文，必须让用户检查并提交。不能把 AI 的建议、普通消息发送或打开任务页视作创建授权。

## 3. 权限与数据边界

- 展示与点击时均检查：当前用户账号能够访问父群和所属项目。无权限时不显示入口；权限发生变化后不得继续进入或提交。
- 项目成员可以创建任务，不把创建权限擅自收紧为管理员专属。UI 操作身份来自当前账号，不把私聊对象当作创建者。
- 创建时重新检查项目存在及访问权限。当前项目固定，不在来自会话的创建流程中切换其他项目。
- 执行负责人只能是当前项目的联系人（AI 身份不作为负责人）；身份名称与类型从稳定 ID 对应的业务数据派生，不能接受表单伪造值。
- **任务身份候选父容器规范**：所有选人入口的候选一律由父容器（任务所属项目）唯一推导，禁止入口自取全局名单。负责人 = 项目联系人；来源者与创建者 = 全部联系人（通讯录）+ 已加入当前项目的 AI 分身与数字员工；写入校验与候选同源，AI 身份不在项目成员范围内一律拒绝。候选面板「联系人」分组内本人（当前操作人 `actorId`）恒排在第一位，其余联系人保持候选原始顺序；检索态仍按相关度排序，不因置顶破坏检索语义。
- 验收人只能是当前项目的联系人。父任务必须属于同一项目；任务详情、评论、子任务和执行历史必须按任务及项目隔离。
- 数字员工能参与项目任务不等于能被拉进群；不能借创建任务绕过成员或身份规则。

## 4. 创建表单

| 字段 | 规则 |
| --- | --- |
| 所属项目 | 顶部路径固定显示当前外层项目，不提供旧 Loop 项目选择器 |
| 标题 | 必填，去除首尾空白后不可为空 |
| 描述 | 可选，支持补充目标、完成标准与背景 |
| 执行负责人 | 可选，默认未指派，候选范围见权限规则 |
| 来源者 | 手动创建时固定为当前操作人本人，不提供选择 |
| 创建者 | 手动创建时固定为当前操作人本人，不提供选择；创建后在详情属性区可改选（候选为全部联系人及已加入当前项目的 AI 分身、数字员工） |
| 状态 | 默认待办，可通过属性胶囊调整；选择状态不触发 AI 执行 |
| 优先级 | 默认无，可调整 |
| 开始日期 | 可选，按 `YYYY-MM-DD` 写入唯一 `start_date` 字段，表示计划开始日，不替代系统自动记录的创建日期；不得晚于截止日期 |
| 截止日期 | 可选，按 `YYYY-MM-DD` 写入任务唯一 `due_date` 字段；创建时可设置，详情属性区可修改或清除 |
| 附件 | 可选，支持一次选择多个文件并按选择顺序上传；每个文件单独校验，当前原型单文件上限 20 MB |
| 任务标签 | 在下拉框中选择或直接输入新建当前项目标签；新建标签名称限 1–20 个字符，提交后关联到该任务 |

按用户最新决定恢复 `7da18d9` 之前的 Loop 创建框结构与公共样式：路径、无边框标题和描述、属性胶囊、底部附件和取消/创建按钮。项目页、子任务和会话右上角入口共用这一组件。创建框不再展示目标、标准、验收人等独立表单行；已有任务数据不受影响。

选中项及候选身份复用公共头像组件；AI 标紧跟姓名。弹层限定在系统标题栏下方：宿主固定在标题栏下沿，Semi 的溢出回弹只在该区域内进行；面板内容区限高（`max-height`）随触发点上下可用空间自适应，长内容内部滚动，内容不足上限时按内容收缩。

任务日期面板与任务下拉菜单沿用王岩确立的浮层契约：`--eva-surface-primary` 背景、`--eva-radius-chip` 圆角、`--eva-shadow-floating` 加 `--eva-shadow-hairline` 的单层投影；浅色与暗色均读取语义 token，不在内外两层重复投影。全局 Semi Dropdown 与 DatePicker 浮层在 `prototype/049-gds-brand-reroot.css` 接入该外观，表格菜单与创建任务的标签菜单分别保留单层外壳。
任务标签选择器负责按名称搜索、关联、移除和直接新建当前项目标签；菜单顺序为顶部搜索、中间匹配标签，非精确名称时在最后提供 Lucide Plus 图标、「新建」和输入名称的中性 Tag。创建后直接关联当前任务。标签支持连续多选与取消，点击标签或新建后菜单保持打开；点击外部或按 Esc 关闭。输入与现有标签名称完全相同时不提供重复新建。暂不提供「管理标签」入口及弹窗，标签片的统一中性外观由公共任务组件控制。
任务筛选面板保留多选，与编辑字段的单选分开。负责人候选复用项目联系人，创建者候选复用全部联系人及当前项目 AI 身份；候选、已选结果、搜索及已保存条件校验使用同一来源，均复用公共头像与 AI 标。状态、优先级和标签候选及回填同样复用公共任务图形与标签片，优先级沿用无、紧急、高、中、低顺序。多选行由公共 `EvaSelectControls` 适配器保持 option 语义，复用公共菜单行皮肤；图标／头像在左，勾选指示在右，不保留空白前置勾选槽。筛选状态由 `IssuePage` 持有，沿用项目级存储与切换重置边界。时间字段与日期范围分行排列，避免日期内容被压缩。
Loop 表单的公共控件皮肤由 `prototype/034-project-task-toolbar-v3.css` 维护；Select 和 DatePicker 只由最外层控件负责边框及焦点，内部 Input 不再套用独立输入框皮肤。控件高度调整须同时检查内部内容的垂直居中。回归见 `tests/browser/task-filter-panel.mjs`，包含在 `npm run test:task-table`。
任务状态和优先级属于单选，菜单统一由公共任务枚举组件以 Semi `Dropdown.Item active` 标明当前值，不再附加对勾或在优先级选项外套第二层胶囊。标签属于多选，保留每项关联状态的勾选指示；标签结果区独立滚动，顶部搜索保持可见。所有选中项的 hover 由全局 Semi 浮层适配层统一补齐，不在业务菜单逐项覆盖。

### 5.1 子任务一期

- 子任务与父任务使用同一任务数据源，通过 `parent_issue_id` 建立关系；父子任务必须属于同一协作项目，不建立独立子任务表或复制项目对象。
- 2026-10-13 按用户确认采用 Multica 的直接子任务组织方式：无子任务时只显示轻量「添加子任务」入口，不展示 0/0、空进度条或重复空状态；有子任务时显示可折叠标题、进度和唯一加号入口，下方仅展示直接子任务的紧凑列表，支持状态及负责人就地修改。子任务还有下一层时在行内显示其直接子任务进度，点击进入该任务详情继续查看。详情顶部保留可点击的项目入口，并完整展示全部任务层级；每个任务层级同时显示完整编号与任务名称，超宽时横向滚动。实际展示的任务层级均可点击，不再提供独立的“返回某任务”入口；属性区的父任务也可切换到上级详情。
- 项目任务页提供“层级”视图，以可展开树形列表展示父子关系；默认展开根任务的第一层子任务。筛选或搜索时保留匹配任务的祖先上下文，项目或筛选结果切换时重置组件展开状态。

### 5.2 任务分解层级

- 详情子任务行前部只展示状态，不展示优先级；优先级仍可在该子任务详情中设置。

- 详情只列当前任务的直接子任务；完整后代关系由项目“层级”视图承担，不提供详情递归树、图形分解画布或“展开全部层级”。
- 详情标题进度、子任务行内下级进度、列表关系提示与层级行进度统一按该任务的直接子任务统计：分子仅为 `done`，分母包括全部直接子任务（含 `cancelled`）；无子任务不显示进度。取消不冒充完成。折叠、搜索和筛选不改变进度口径；层级页筛选只影响展示，不影响基于完整当前项目数据的统计。
- 完成／删除约束与显示进度分开：完成父任务仍检查未完成且未取消的直接子任务并要求确认，批量完成仍先要求处理；不级联完成任何后代，环检测继续遍历完整后代关系。
- 详情折叠状态由当前子任务组件持有，切换任务重置为展开；进度由唯一任务数据源实时派生，不另存计数或 DOM 状态。归档项目隐藏新增和编辑入口，仍可阅读和打开直接子任务。
- 详情面包屑使用公共 Semi Breadcrumb，保留 Lucide ChevronRight 分隔符和 Eva 视觉 token，完整展示项目与所有祖先及当前任务编号、名称，不折叠、不省略、不缩进。路径超宽时横向滚动，首次打开直接定位当前任务；原位切换任务保留切换前滚动位置，仅在目标不可见时从该位置平滑定位；超长当前项优先显示编号和标题开头，减少动态效果时直接定位。手动滚动不自动拉回；项目与任务导航继续使用既有原位切换。右侧「父任务」作为独立可折叠模块，排在「属性」下方、「详情」上方，使用相同的原位切换行为。
