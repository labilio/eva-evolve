# 会话列表右键菜单

适用范围：我的消息的最近页与关注页。复用共享右键菜单与 Octo 的 Lucide 语义，不改变列表字号、间距、圆角及拖拽排序。

| 对象 | 操作 |
| --- | --- |
| 最近会话 | 置顶／取消置顶、清除未读、设为／取消免打扰、不显示该会话 |
| 关注大群、私聊 | 清除未读、设为／取消免打扰；非项目会话另提供移动到分组及新建分组 |
| 关注子区 | 清除未读、设为／取消免打扰、隐藏子区 |
| 个人分组标题 | 编辑分组 |

清除未读仅在存在未读时显示。最近页置顶仍置于顶部并使用灰底；关注页不提供置顶。项目会话不移动到个人分组，子区随父群归类。隐藏子区沿用子区信息中的偏好与恢复入口。

状态统一由 EvaMembership 按当前账号保存。子区免打扰默认继承父群，显式设置后优先使用子区值。右键打开菜单不切换当前会话、不重建聊天流和输入框，保留草稿。点击外部、按 Escape 或切换页签关闭菜单；支持方向键及 Shift+F10。

图标沿用 Pin／PinOff、BrushCleaning、Bell／BellOff、EyeOff、FolderInput、FolderPlus、Pencil；二级菜单使用 ChevronRight。不增加关注／取消关注或删除分组能力。

“不显示该会话”仅移出最近页并清除旧未读，不影响关注、记录、成员资格及右侧当前内容。新消息到来后恢复最近行，保留原置顶偏好；搜索仍可找到该会话。与关注页“隐藏子区”是两个独立状态。
