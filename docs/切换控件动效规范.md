# 切换控件动效规范

本规范只用于明确的视图切换器，不根据 `role="tab"`、选中背景或横向排列自动判断适用范围。用户确认：弹窗内默认出现的选项、查询分类与筛选不能全套使用滑动动画。

## 适用范围

当前仅接入以下明确切换器：

| 入口 | 切换内容 |
| --- | --- |
| 我的消息：关注／最近 | 两种会话列表视图 |
| 项目任务：看板／列表／层级 | 同一任务集合的展示方式 |
| 个人自动化：定时任务／运行记录 | 任务管理与运行历史视图 |

以下入口保留原有反馈，不接入本规范的滑动选中背景或指示线：子区管理状态选项、聊天搜索的全部／消息／图片视频／文件、查询筛选、连接中心分类、技能来源选项、AI 配置与创建表单页签、项目导航页签、一级导航、下拉选择、开关、树展开和排序拖拽。它们存在选中态，不代表就是本规范中的切换器。后续新增入口先判断产品语义，不能批量套用所有 tabs 或按钮。

## 动效合同

- 保留当前外形、颜色、圆角和阴影，同一个选中背景滑向目标项；文字颜色同步过渡。
- **首次打开、挂载或恢复默认选中态时，直接呈现最终位置，不播放切换动画。** 仅用户切换已有控件时播放。
- 业务视图立即切换，不等待动画结束，不新增点击锁、延时或页面整体滑入。
- 快速连续点击从当前位置转向最后目标，不排队、不弹跳。
- 不改变按钮或容器整体高度，不使用缩放；尺寸变化直接适配布局，不当作一次用户切换。
- `prefers-reduced-motion: reduce` 时关闭过渡，直接显示最终状态。

公共 Eva 适配 token 位于 `prototype/008-gds-tokens.css`，不修改客户原始 GDS 包：

| Token | 参数 |
| --- | --- |
| `--eva-switch-duration` | 220ms |
| `--eva-switch-easing` | cubic-bezier(.22,1,.36,1) |
| `--eva-switch-color-duration` | 180ms |

## 实现边界

现有等宽切换器使用同一个 CSS 伪元素背景；位置由原 React 选中状态推导。不新增另一份业务选中状态，不使用全局 MutationObserver、捕获点击监听或定时器模拟切换。指示器使用 `pointer-events: none`，不占焦点，不阻挡点击；保留原有键盘、禁用和可见焦点行为。

实现位于 `039-team-message-project-recent.css`、`034-project-task-toolbar-v3.css` 和 `031-shared-automation-v2.css`。禁止全局覆盖 Semi Tabs，禁止使用 `transition: all`，禁止为了统一动画重建表单或选项控件。

## 验收

本地 HTTP 浏览器检查：首次显示没有切换动画；往返切换有中间位移且最终位置正确；快速点击落在最后目标；减少动态效果时即时完成；离开再返回保留原有状态边界。对上述排除入口检查没有新增滑动指示器或全局动画规则。

回归脚本：`tests/browser/switch-motion.mjs`。检查与发布分级遵循 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 最近页群内切换（2026-10-08）

用户确认采用 Telegram 群内切换策略，默认会话命名为「主聊天」，使用 Lucide MessageCircle；子区保留 CornerDownRight，主聊天与子区之间保留竖分隔线。不增加「全部」消息聚合入口。

用户验看后否定自定义滑动效果，确认改用 Semi Tabs。最近页群内导航由 `EvaRecentTopicNavigation` 适配现有 Semi `Tabs`（line、medium、受控 activeKey、collapsible），选中会话仍由 `ChannelsView` 管理。删除自定义指示线、几何测量、ResizeObserver、滚动动画与键盘控制；选中反馈、键盘焦点和溢出滚动使用 Semi 原生实现。聊天流与输入框保持既有内核，`tabPaneMotion` 关闭，页签不另建聊天面板。该入口不套用本规范上方的公共滑动指示器。

范围仅最近页，不接入关注、项目或我的 AI。消息、搜索、转发和权限继续由现有 IM 内核按会话处理。最近页群聊草稿按账号与会话 ID 保存在当前 React 会话组件中；切换主聊天与子区可恢复，发送成功后清除。该补齐不提供刷新后持久化，也不改变私聊与我的 AI 的既有草稿数据源。参考 TelegramSwift `579cebbf0c01fd41b712eff3647fa7f69db9665d` 的 `MonoforumHorizontalView.swift`、`ScrollableSegmentView.swift` 和 `ChatController.swift:6418`；这是已保存的本地源码版本，非最新发行版声明。


### 后续用户确认：补充轻量动效

保留 Semi Tabs 的导航、键盘和溢出能力；通过组件内部 ref 测量受控选中项，单一下划线使用公共 220ms token 移动。首次挂载、尺寸变化及溢出滚动直接定位。切换时仅既有消息流做 120ms 淡入，不重建聊天面板或输入框；快速切换取消前次淡入，减少动态效果时关闭。该决定替代上文“不增加自定义指示线”的限制，仍仅限最近页。

### 子区新消息提醒（2026-10-08）

参考同版本 TelegramSwift `MonoforumHorizontalView.swift:64–115` 与 `ScrollableSegmentView.swift:344–346`：话题文字后带紧凑数字徽标，有未读才显示，未静音用强调色、静音用灰色；选中态不替代消息提醒。Eva 保留自身明暗主题 token 和 99+ 数量上限。用户随后确认使用 Eva 既有浅蓝底、蓝色数字胶囊，直接复用 017 的共享未读徽标样式（16px 高、11px 字号、500 字重），不采用 Telegram 实心蓝底白字。主聊天也能显示自身的计数，左栏父群计数继续汇总主聊天与可见子区。

按用户要求，最近页演示提醒常驻，查看或刷新不消耗预置计数；预置由 `009-3-data-im.js` 的 `__EVA_RECENT_UNREAD_DEMO` 维护，仅限指定供应链会话，不修改真实已读记录和用户静音偏好，不影响关注／项目。正常新增会话无强制提醒。回归为 `tests/browser/recent-topic-unread.mjs`。
