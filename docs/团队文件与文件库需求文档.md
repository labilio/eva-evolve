# 团队文件与文件库需求文档

> 状态：原型方案（V7）
> 权限基线：[文件库角色与权限矩阵](./file-library-permissions/index.html)

## 1. 目标

完善【项目 → 团队文件】和一级入口【文件库】，让用户在个人空间、项目空间中上传、保存、查找、归类和追溯本地文件与外部链接。

核心原则：**同一套文件数据、同一套权限判断、不同入口按空间范围展示。**

## 2. 两类空间

| 空间 | 数量 | 成员与角色 | 文件归属 |
| --- | --- | --- | --- |
| 个人空间 | 每人一个 | 本人固定为 Owner | 归个人空间 |
| 项目空间 | 用户可加入多个 | 项目负责人为 Owner，项目管理员为 Manager，普通成员为 Editor | 归具体项目空间 |

- 文件本身不设 Owner，Owner 是空间角色。
- 项目【团队文件】和文件库中的同一项目空间共用文件 ID、目录和权限结果。
- 任务负责人可以是专家、专家团、数字员工或人类，不改变任务产出的项目空间归属。

## 3. 页面设计

### 3.1 文件库

- 左侧“文件空间”展示“个人空间／项目空间”；项目空间下列出用户已加入的具体空间。
- 点击项目空间一级入口，先展示空间卡片；点击具体空间后进入文件列表。
- 从文件库上传时，可以选择本人有写入权限的空间。
- 进入任意文件夹后显示“返回上一级”和当前位置。
- 空间内仅搜索当前位置，不做全局搜索。

### 3.2 项目团队文件

- 默认进入当前项目文件根目录，不再次选择空间。
- 项目群全员都可以将群文件保存到本项目文件管理；保存后生成独立副本，不扩大来源群聊权限。
- 任务产出自动写入任务所属项目空间，并自动关联对应任务。
- 进入文件夹后显示“返回上一级”和当前位置。

### 3.3 文件列表

普通文件列表字段统一为：

| 字段 | 说明 |
| --- | --- |
| 名称 | 文件名或链接名称；下一行最多展示 2 个自定义标签，超出显示 `+N`；点击文件名直接打开预览，点击外部链接名在新窗口打开原地址，点击文件夹名进入文件夹 |
| 文件类型 | 本地文件按扩展名自动识别：PDF、Word、Excel、PPT、图片、音频、视频、压缩包、文本、其他；外部链接显示来源平台和资源类型；文件夹显示“文件夹” |
| 关联内容 | 只读展示系统自动建立的任务、来源群聊／私聊或来源文件；外部链接展示来源平台和域名，最多 2 条 |
| 大小 | 文件大小；文件夹和外部链接显示 `—`；普通文件快捷方式显示源文件大小 |
| 创建信息 | 创建者和创建时间 |
| 操作 | 普通文件和文件夹显示三点按钮；点击后展开当前角色可执行的操作，其中“查看文件信息”打开详情弹窗 |

回收站字段为：**名称、文件类型、原位置、大小、删除信息、操作**。

三点菜单按对象、状态和权限动态展示：文件可显示预览、下载、查看文件信息、复制内部链接、重命名、移动、创建副本、创建快捷方式、编辑标签和移至回收站；外部链接可显示打开原链接、复制外部链接、查看文件信息、复制内部链接、重命名、编辑链接、移动、创建快捷方式、编辑标签和移至回收站，不提供预览、下载或创建副本；文件夹不显示预览、下载、标签与快捷方式；回收站仅显示查看文件信息、恢复和永久删除。无权限的动作不展示。“文件信息”只能通过三点菜单中的“查看文件信息”打开，点击文件名、文件行或预览失败都不得打开文件信息弹窗。文件库与项目团队文件必须使用一致的规则。

文件夹及其内部内容作为一个删除单元进入回收站：回收站只展示被直接删除的文件夹，不平铺内部文件，也不允许单独恢复或永久删除随文件夹进入回收站的子项。恢复文件夹时恢复整个目录树；原父目录不存在或仍在回收站时，恢复到当前空间根目录。永久删除文件夹时，只删除该删除单元中仍在回收站的内容，不能删除已经恢复的文件。

不设置手工“业务类别”。文件格式由系统识别，自定义归类使用标签完成。

### 3.4 文件预览与文件详情

- 点击文件名或“预览”后，从当前内容区右侧打开预览侧栏，不使用居中弹窗，不覆盖客户端系统标题栏。
- 点击预览侧栏之外的区域或按 `Esc` 关闭预览侧栏；侧栏内操作不触发关闭。
- “查看文件信息”使用居中弹窗展示详情，不再占用右侧侧栏。
- 演示中的 Word、Excel、PPT、Markdown 和压缩包都必须有可辨识内容：Word 使用分页纸张，Excel 使用可滚动表格与工作表标签，PPT 使用 16:9 幻灯片与翻页控件，Markdown 支持阅读／源码切换，压缩包展示目录、类型与大小。不得回退到统一空占位。

详情分为“操作、标签、系统关联、快捷方式信息、文件信息”：

- Owner、Manager、Editor 都可添加、修改和移除标签。
- 标签使用可输入下拉框：下拉展示并可选择当前空间已有标签；输入时过滤候选，未命中时按回车新建标签。
- 每个文件或快捷方式最多 8 个标签，每个标签最多 20 个字符；自动去空格、去重。
- 标签只属于当前文件或快捷方式，不影响权限，也不修改源文件标签。
- 系统关联只能由产生过程自动生成，用户不能添加、删除或修改。
- 任务产出自动关联任务；从群聊、私聊或“我的 AI”会话保存时自动关联来源会话；创建副本自动增加来源文件关联；普通上传默认无关联。
- 系统关联只用于追溯，不授予来源任务、群聊或文件的访问权限；无来源权限时进行脱敏。
- 有来源权限时可从详情返回来源会话并定位到原文件消息；来源会话已删除或不可访问时，不跳转并显示不可用状态。
- 文件信息展示文件类型、所在位置、产生方式、创建者、创建时间和大小，不展示最后编辑者或更新时间。
- 外部链接详情额外展示来源平台、链接域名及“内容与版本由原平台维护”，外部完整地址通过“复制外部链接”获取。

### 3.5 会话文件存入文件库

- AI 生成的文件、私聊传输的文件和群聊文件默认只存在于原会话，不自动进入文件库。
- 文件卡和右键菜单统一提供“存到文件库”。项目群聊中的文件点击后直接保存到所属项目空间根目录，不选择目标空间或文件夹；私聊、“我的 AI”和非项目群聊中的文件仍由用户选择本人可写入的空间及目标文件夹后确认保存。保存成功后按钮变为“前往文件库查看”。
- 保存结果是目标空间中的独立文件，不是在线文档，也不是指向会话临时附件的快捷方式。
- 保存人为创建者；文件访问权限完全继承目标空间。AI、原发送人和任务负责人只记录为来源信息，不成为文件 Owner，也不获得额外权限。
- 同一来源附件的同一版本重复保存到同一目标文件夹时直接返回已有文件；保存到不同位置允许存在。不同附件同名时自动生成 `文件名 (2)`、`文件名 (3)`。
- 来源会话删除不删除已保存文件，已保存文件删除也不影响原会话附件。
- 保存完成后可直接打开所在位置及文件详情；项目群文件默认定位到所属项目空间根目录。

### 3.6 外部链接与外部文件夹存入文件库

- 项目团队文件和文件库中的个人、项目空间统一提供“添加外部资源”，下分“外部文件夹”和“普通外部链接”；名称和 URL 必填。
- 外部链接是独立资源类型 `external_link`，与文件、文件夹、快捷方式使用同一套 ID、目录、标签、回收站和空间权限，不伪装成本地文件或在线文档。
- 外部文件夹沿用 `external_link`，通过 `external.kind = folder` 表达。它是原平台文件夹的访问入口，不是 Eva 内部 `folder`：点击后在新窗口打开原文件夹，不进入 Eva 面包屑，也不能在其中上传 Eva 文件。
- 仅接受不含账号密码的 `http`、`https` 地址；自动识别飞书、企业微信和普通网页，并记录规范化 URL、来源平台、资源类型与域名。
- 飞书等具有稳定文件夹路径的链接自动识别资源类型和资源 token；企业微信微盘等无法仅凭分享地址判断类型时，由用户在“外部文件夹”入口确认后保存。明确识别为文档、表格或页面的链接不能从“外部文件夹”入口保存。
- 同一空间、同一文件夹内的等价 URL 只保留一个入口；保存到不同文件夹允许存在。
- 可提取平台资源 token 时按“平台 + 资源类型 + token”去重，忽略不影响资源身份的分享来源参数；无法提取时按规范化 URL 去重。
- 编辑链接时若域名发生变化，必须再次确认新域名可信；未确认不得覆盖原地址。
- 打开时使用新窗口，并隔离 `window.opener`；不抓取外部页面正文、缩略图、评论或权限信息。
- 外部内容的可访问性仍由原平台决定；Eva 空间权限只控制谁能看到、整理和打开这个入口。
- 外部文件夹支持标签、内部链接、跨空间快捷方式、重命名、编辑链接、空间内移动和回收站；不提供预览、下载、创建副本、子项展开或内容同步。

## 4. 文件快捷方式

- 普通文件和外部链接可在其他有写入权限的个人或项目空间中创建快捷方式；本期不支持文件夹快捷方式。
- 快捷方式是引用，不复制源文件，不复制源文件标签，也不扩大源文件权限。
- 创建时必须同时满足“源文件可读”和“目标空间可写”。打开、预览、下载时再次校验源文件权限。
- 不能对快捷方式再次创建快捷方式；同一目标文件夹内不能重复创建同一源文件的快捷方式。
- 快捷方式可以重命名、移动、维护标签；这些操作由目标空间角色控制，不影响源文件。
- 未自定义名称时，源文件重命名会同步到快捷方式；自定义后不再同步。
- 源文件移动不影响快捷方式；源文件进入回收站或永久删除后显示“源文件已失效”。
- 用户失去源空间权限后显示“无权访问的快捷方式”，不展示源文件名称、标签或关联内容。
- 删除快捷方式只删除引用，不删除源文件；仍只有 Owner、Manager 可执行删除。

## 5. 权限

| 动作 | Owner | Manager | Editor |
| --- | :---: | :---: | :---: |
| 浏览、预览／打开、下载、复制内部链接 | ✓ | ✓ | ✓ |
| 上传、添加／编辑外部链接、新建文件夹、重命名、空间内移动与复制 | ✓ | ✓ | ✓ |
| 编辑标签、创建跨空间快捷方式 | ✓ | ✓ | ✓ |
| 删除、查看回收站、恢复、永久删除 | ✓ | ✓ | — |
| 管理普通成员、空间链接、设置、审计 | ✓ | ✓ | — |
| 设置或取消 Manager | ✓ | — | — |
| 转移空间所有权 | ✓ | — | — |

补充规则：

- 不设置 Viewer，不做文件级独立角色。
- 内部链接和快捷方式都只用于定位，不授予权限。
- 项目成员退出后立即失去项目文件访问权。
- 上传者、群文件保存者和任务执行者只记录为创建者或来源，不获得额外权限。
- 保存会话文件时同时校验“当前用户可读来源会话”和“当前用户可写目标空间”；系统关联不能作为权限凭证。
- 外部链接本身不会绕过原平台鉴权；复制内部链接或创建快捷方式也不会授予源空间权限。

## 6. 本期不做

- 在线文档创建或协同编辑。
- 外部页面抓取、内容预览、版本同步和可用性监控。
- 文件版本管理。
- 外部公开分享和文件级独立权限。
- 跨空间移动或复制；跨空间只支持创建快捷方式。
- 文件夹快捷方式和快捷方式嵌套。
- 全局搜索。
- 手动添加、删除或修改文件关联。

## 7. 核心验收标准

1. 项目空间可存在多个，用户进入具体空间后按角色操作文件。
2. Editor 可上传、整理文件和编辑标签，但不能删除文件或访问回收站。
3. Owner、Manager 可管理回收站；只有 Owner 可设置 Manager 和转移空间所有权。
4. 项目团队文件与文件库中的项目空间展示同一份数据。
5. 列表统一展示名称、文件类型、关联内容、大小、创建信息和操作，不出现业务类别或更新时间。
6. 标签可自定义；系统关联只读，且不会扩大来源权限。
7. 普通文件可向其他可写空间创建快捷方式，不能跨空间移动或复制。
8. 快捷方式失去源权限时必须脱敏，源文件删除后必须失效。
9. 页面中不出现 Viewer、文件 Owner、在线文档、版本管理或手动关联入口。
10. 删除文件夹后，回收站只展示文件夹根项；恢复和永久删除按整个删除单元执行，且永久删除不能影响已经恢复的文件。
11. AI 生成文件、私聊附件和群聊文件在用户确认前不进入文件库；项目群文件直接存入所属项目根目录，其他会话须选择目标位置。
12. 保存后文件按目标空间权限访问，来源关联只读、可回跳且在无来源权限时脱敏。
13. 个人空间和项目空间都可保存外部链接；同一资源在项目文件和文件库中 ID 一致，危险协议被拒绝，改域需确认，且外链不出现预览、下载或创建副本。
14. 飞书、企业微信及其他平台文件夹可作为 `external_link + folder` 保存；列表必须与本地文件夹视觉可区分，点击只打开原平台，同一目录按资源身份去重，且两个文件入口共享同一资源 ID。
