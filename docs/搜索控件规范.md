# 搜索控件

2026-09-09 用户确认：搜索采用简洁外观，不显示快捷键提示。两种入口并存：直接输入的搜索框，以及打开既有搜索界面的图标按钮。不得为了统一外观新建搜索功能或改变搜索范围。

## 统一外观

- 输入框只有一层外框，使用 GDS 的白色表面、弱灰边框和 8px 控件圆角。
- 常规高度 32px，左右内边距 12px，Lucide Search 图标 16px，图文间距 8px，文字 14px；宽度、外边距和响应式由页面布局负责。
- 获得焦点时仅边框变为 Eva 主蓝色，保持边框厚度和控件尺寸，不增加发光阴影。失焦恢复默认边框。
- 搜索图标按钮保持紧凑入口，使用公共中性图标色、悬停背景和键盘焦点环；不将按钮强行替换为常驻输入框。
- 由搜索图标按钮点开的输入框不再重复显示搜索图标：按钮本身是唯一入口标识。该输入框仍使用同一套公共外观，通过语义类接入 `prototype/055-search-controls.css`，不在页面内自行维护边框或聚焦效果。
- 保留各入口既有的清空、禁用、搜索范围及查询状态。未实现的搜索入口不因本次样式统一而变为可用。
- 文件库和项目文件打开右侧文件预览时，搜索框由页面布局将宽度上限收敛为 240px 并继续右对齐；更窄内容区不超过可用宽度，关闭预览后恢复常规 320px 上限。宽度变化不得重建输入节点或清空查询。

## 实现归属

`prototype/055-search-controls.css` 是搜索外观的公共适配层。Semi 搜索框通过直接前缀中的 `.lucide-search` 接入，原生文件库和连接中心搜索使用已有语义类接入，不按 placeholder 文案猜测。

新增搜索优先复用 Semi Input，使用 Lucide Search 作为 prefix；不再额外包一层有边框的容器。原生输入框保留原有事件控制器。页面 CSS 只负责宽度和所在位置，不独立维护颜色、图标间距或聚焦效果。

数字员工市场的统一搜索是「可输入触发框 + 结果菜单」形态，不属于图标按钮点开的输入框：触发区是带 Lucide Search 前缀的 Semi Input，直接在外层框内输入，因此命中上方通用外观规则；结果菜单用 Semi Dropdown 承载，`trigger:'custom'`，由页面控制器管理开合，并在组件级监听外部 `mousedown` 收起。外层已有搜索框，菜单内不得再出现第二个搜索框。菜单的分组标题、结果行、「展开其余」与滚动复用任务「选择负责人」下拉的 `.eva-task-assignee-*` 皮肤与 DOM 合同，只在市场作用域覆盖 `min-height`／`max-height`，不修改该公共皮肤。

我的 Agent 中栏原生列表与搜索结果共用同一个分组标题组件 `aiTeamSectionHeading`（`.eva-ai-team__section-heading` / `-label` / `-rule`）：标题 + 右侧拖尾细线，细线与文字由该行的 `align-items:center` 垂直居中。细线始终渲染，是否省略首组由**父容器**按 `:first-child` 判定（`.eva-ai-team__roles` 下的分组节点、`.eva-ai-team__search-results` 下的标题行），组件本身不持有「第一组」状态，与拉人模板 §5.1 的父容器管理规范一致。组内（标题→内容）沿用各自原间距（AI 小队／搜索标题行 4px、可折叠角色组由 32px 行垂直居中给 8px）；**组间**由父容器一份变量 `--eva-ai-team-group-margin`（8px）统一分隔，原生角色分组、AI 小队与单聊、搜索结果各组一致，不写在标题行或行内部。字档为 GDS caption 12/16/400、字色 secondaryAccessible；可折叠分组的标题挂在既有 `.eva-ai-team__group-toggle` 内，沿用 toggle 自身的高度与留白。原生列表不再使用独立的 `.eva-ai-team__list-divider`，AI 小队与云端分身／个人助理／数字员工一律用同一分组标题表达，两处外观完全一致。

验证默认、悬停、鼠标/键盘聚焦、输入与清空；页面切换及返回时遵循各入口原有的查询保留/重置边界，不遗留焦点样式。搜索不改变系统标题栏、会话消息、身份及业务权限。

## 自动回归检查

运行 `npm ci`、`npm run build`，再运行 `npm run test:search`。脚本自行启动临时本地 HTTP 服务并释放资源，不依赖已运行的预览服务；macOS 使用已安装的 Edge，其他系统先运行 `npx playwright install chromium`。GitHub quality gate 自动安装 Chromium 并执行同一组测试。

浏览器测试文件为 `tests/browser/search-controls.mjs`，覆盖：

- 项目、通讯录、文件库、连接中心四处常驻搜索框；团队消息（关注／最近）中栏不保留常驻搜索框；我的 Agent 中栏以标题行图标按钮打开搜索（输入框不再重复显示搜索图标），命中会话标题或 AI 名称（个人助理／云端分身／数字员工／AI 小队），结果按「分类 → AI 身份 → 会话」三级给出：分类作分组标题（AI 小队／云端分身／个人助理／数字员工），身份作父行（头像 + 名称 + AI 标），命中会话缩进挂在父行下，从属关系由层级表达、不再逐行重复归属身份；身份名命中或会话命中都会带出父身份，故无会话的身份也可搜到。分组标题为「标题 + 右侧拖尾细线」（第一组不拖线），结果行直接复用中栏原生列表的 team／identity／session 行 markup（身份行复用公共头像与 `eva-identity-name-row`／`eva-identity-name-text`，会话行复用 `eva-ai-team__session-title`），外观与列表完全一致、不另造行样式，每个身份默认上限 5 条并显示「展开其余 N 条」；数字员工市场使用可输入触发框 + 结果菜单，菜单内不出现第二个搜索框。
- 单层边框、32px 高度、12px 留白；带图标的常驻搜索框保持 16px 线性图标和 8px 图文间距，图标按钮点开的输入框按上述规则不重复显示图标。
- 默认、悬停、聚焦和失焦；蓝框不改变尺寸，不出现额外阴影或外框。
- 中文筛选、无结果、清空恢复、Escape 清空和页面往返隔离。
- 键盘聚焦及中文输入法组合/提交时保持输入节点。
- 文件库与项目文件打开、关闭右侧预览时搜索框宽度自适应，并保持最右对齐。
- 图标按钮样式夹具的悬停、键盘焦点和禁用行为。夹具不代表产品新增了搜索面板。
- 我的 Agent 会话搜索（`tests/browser/my-ai-session-search.mjs`）：标题行 32px 图标按钮打开输入框，输入框不重复显示搜索图标；命中会话标题或 AI 名称（个人助理／云端分身／数字员工／AI 小队）；结果按「分类 → AI 身份 → 会话」三级给出，分类为分组标题（AI 小队／云端分身／个人助理／数字员工），身份作父行（头像 + 名称 + AI 标），命中会话缩进挂在父行下、不再重复归属身份，身份名命中或会话命中都会带出父身份（无会话的身份也可搜到），标题后拖一条与文字垂直居中的细线（第一组不拖线），每个身份默认 5 条并显示「展开其余 N 条」，结果行直接复用中栏原生列表的 team／identity／session 行 markup、外观与列表完全一致，命中词在身份名／会话名上着色高亮（与仓库既有会话内搜索命中同源）；结果与中栏原生列表共用同一分组标题组件（标题 + 右侧拖尾细线），首组不拖线由父容器 `:first-child` 判定；点击结果或侧栏普通会话后关闭且不抢焦点，点击搜索区外或按 Escape 关闭并回到搜索入口，空查询回到原层级，全程不新建会话。
