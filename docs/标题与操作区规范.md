# 标题与操作区规范

2026-09-09：统一同层级标题，保留不同业务动作。共同样式所有者是 `prototype/056-heading-system.css`，业务页面不得另设同类字号与间距。

| 层级 | 字体 | 几何与适用范围 |
| --- | --- | --- |
| 一级功能标题 | 16px / 24px，500 | 48px 高、左右 16px；消息、Agent、项目群聊、个人 Eva、通讯录、连接中心、任务看板、文件库。不按两栏或三栏区分规格；说明放在标题栏下方的内容区，不增高一级标题栏 |
| 分区标题 | 14px / 22px，500 | 内容内分区；保持对应内容的布局与折叠关系 |

列表面板操作按钮统一 32px，图标 16px。标题与按钮分开排布，长标题单行省略；键盘焦点明确。个人 Eva 保留铅笔图标和新建会话行为；消息、Agent、项目群聊保留 plus 及对应创建菜单。文件库导航标题没有创建动作，不增加按钮。

个人首页品牌欢迎语、聊天身份标题、任务详情和文件预览沿用各自已有的业务组件合同；不使用全局 h1/h2 规则覆盖它们。分身名字、AI 标记与头像不受标题规范影响。

新老版保留各自文件夹、分组和演示数据。标题统一不能删除搜索、筛选、权限或改变按钮含义。此前已明确移除的消息列表搜索按本轮决定保持。

本地验收覆盖两个版本、1200px 与 1000px 视口、所有四处列表面板、个人新建会话、三类加号、页面切换及相关搜索。页面级操作栏按内容自然换行，不缩小按钮或遮挡标题。

一级功能标题不添加装饰性前置图标；只在操作区保留有实际行为的按钮。项目选择器、会话身份头像和返回按钮分别表达对象身份或操作，不属于装饰标题图标。

## 自动化约束

所有一级功能页共用同一个固定标题合同，不允许按页面设置 42px、64px 或其他高度例外。标题栏紧接系统标题栏，文字距标题栏左侧 16px 并垂直居中。通讯录表头等内容分区不能替代或改变一级标题栏。

几何与字体由 `prototype/056-heading-system.css` 唯一管理。新增一级页面必须接入公共标题样式，并登记到 `tests/browser/heading-system.mjs` 的路由清单；各路由不得自带不同的期望规格。现有 `test:headings` 质量检查覆盖 1200px、1000px 视口及页面操作，故障注入必须证明 42px 高度、20px 字号和下移 16px 均会失败，恢复后通过。

设计稿不是修改项目级合同的授权。规范冲突应修正实现，不能增加页面例外、放宽断言或跳过检查。

相邻会话身份标题栏与中栏标题栏的上下边缘必须严格对齐，总高 48px 包含底边框，统一使用 border-box。身份标题保留业务字体和头像；不得因 content-box 额外增加 1px。浏览器门禁直接比较两栏边界，并注入 1px 偏差验证拦截。
