# 标题与操作区规范

2026-09-09：统一同层级标题，保留不同业务动作。共同样式所有者是 `prototype/056-heading-system.css`，业务页面不得另设同类字号与间距。

| 层级 | 字体 | 几何与适用范围 |
| --- | --- | --- |
| 一级功能标题 | 16px / 24px，500 | 48px 高、左右 16px；消息、Agent、项目群聊、个人 Eva、通讯录、连接中心、任务看板、文件库。不按两栏或三栏区分规格；带说明的内容区允许自然增高 |
| 分区标题 | 14px / 22px，500 | 内容内分区；保持对应内容的布局与折叠关系 |

列表面板操作按钮统一 32px，图标 16px。标题与按钮分开排布，长标题单行省略；键盘焦点明确。个人 Eva 保留铅笔图标和新建会话行为；消息、Agent、项目群聊保留 plus 及对应创建菜单。文件库导航标题没有创建动作，不增加按钮。

个人首页品牌欢迎语、聊天身份标题、任务详情和文件预览沿用各自已有的业务组件合同；不使用全局 h1/h2 规则覆盖它们。分身名字、AI 标记与头像不受标题规范影响。

新老版保留各自文件夹、分组和演示数据。标题统一不能删除搜索、筛选、权限或改变按钮含义。此前已明确移除的消息列表搜索按本轮决定保持。

本地验收覆盖两个版本、1200px 与 1000px 视口、所有四处列表面板、个人新建会话、三类加号、页面切换及相关搜索。页面级操作栏按内容自然换行，不缩小按钮或遮挡标题。

一级功能标题不添加装饰性前置图标；只在操作区保留有实际行为的按钮。项目选择器、会话身份头像和返回按钮分别表达对象身份或操作，不属于装饰标题图标。
