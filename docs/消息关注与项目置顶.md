# 消息关注与项目置顶

- 项目页置顶与消息关注共用成员数据仓库中的账号级项目置顶列表。置顶项目后，关注展示该项目下当前账号可访问的全部大群；未来新建或获得访问权限的群自动加入。取消置顶后，该项目分类退出关注，最近会话仍可访问。
- 置顶不授予项目或群访问权限。群内子区保留在父群下，不变成独立项目或分类。
- 私聊、非项目群及独立演示会话统一归入“其他会话”。
- 参照 Octo-Web ConversationListGrouped，通过六点手柄排序分类，以及分类内部的大群/私聊；子区随父群移动。不支持跨分类拖动改变项目归属。
- 拖动顺序按账号保存在成员数据仓库；新增项目/群追加到已保存顺序末尾。切换关注/最近沿用统一 IM 会话与输入区。
- 列表和页签由 ChannelsView 的 React 状态维护，旧 040 DOM 页签与最近列表实现已删除。搜索与新建群聊入口继续复用原有组件和选人模板。

本轮按用户要求不运行测试或浏览器验收；构建完成不等于交互验收完成。

## 会话项目归属

最近按独立会话混排，父群、子区与私聊各自维护时间、摘要、未读、草稿和选中态；子区消息不得改写父群行。最近行不额外显示项目路径；私聊与非项目群也不伪造项目归属。关注和项目内列表保持原有层级；聊天顶部第二行仅显示项目图标与项目名，第一行保留大群／子区层级，聊天信息的“所属项目”可进入对应项目。

## 子区生命周期与个人偏好（2026-10-15）

- 普通群和 AI 小队子区统一为活跃 ⇄ 归档 → 软删除。归档后只读：可查看、搜索、复制、转发和保存已有内容；不可发送、回复、撤回、删除或清空消息、重命名、调整置顶／免打扰、编辑或删除协作说明。需要先独立恢复，再进行修改；归档不改变成员继承。
- 已归档列表三点菜单仅保留「复制子区链接」和管理者可用的「恢复子区」。软删除仍只使用列表垃圾桶，不在菜单重复；子区信息保留只读资料和有权限的恢复入口。原置顶、免打扰偏好保留，恢复后沿用。
- 子区不提供独立关注或隐藏。关注由父群／项目推导；旧隐藏与被 @ 恢复配置清理后，原子区按活跃或归档恢复展示，不修改消息或草稿。
- 保留账号级置顶、免打扰；置顶只改变父群内顺序，免打扰保留父群继承。个人清空记录不改变其他成员历史。
- 父群聊天标题栏「子区」打开共享列表，仅有「活跃中／已归档」。已归档行右侧提供小垃圾桶；只对现有子区管理者显示，使用公共 Popconfirm 确认。活跃列表、右键菜单及子区信息面板均不提供删除。
- Popconfirm 标题「删除这个子区？」，说明「删除后将无法查看该子区及其聊天记录。」，按钮「取消／删除」。取消及 Escape 不写入；确认时重新校验权限与已归档状态。
- 普通群管理者沿用子区创建者／群主／群管理员；项目已归档时遵循原项目只读边界。AI 小队沿用本人的管理边界。
- 必须先在独立操作中归档，再软删除；禁止同时提交归档和删除以绕过前置状态。保留原子区、消息及 deletedAt/deletedBy，列表、搜索、转发目标及旧链接不可再访问；不提供恢复已删除入口。
- 本地原型在现有浏览器存储模拟留痕，不新增服务端、审计产品入口或 Supabase 业务数据。AI 单聊 session 不套用本规则。
- 子区生命周期清理不改变「最近」的独立会话行、父群归属和路由语义；仅共享子区能力随本规则清理。

## 2026-09-14 关注列表层级

参照设计师 v132 文件，分类标题使用灰色 13px、700 字重，不增加标题背景、悬停底色或项目色文字；标题左内边距 14px，项目文字起点对齐大群头像（含 10px 折叠箭头和 4px 间隔）。大群图标起点为 28px，子区箭头起点对齐父群名称（28px 大群内边距＋22px 头像槽＋8px 间隔），保留当前头像、项目色跳转图标、字号和未读状态。分类及大群拖拽手柄浮在左侧预留槽位，不参与文字排版。分类宽度随中栏变化，不复制固定 212px 宽度。仅作用于关注分类树，不调整最近列表、个人 Eva 或我的 Agent。

关注分类内的大群和子区行统一使用设计师 v132 的 8px 圆角，hover 为 #F5F6F7，选中及选中后 hover 为 #F0F1F2；项目分类标题继续无底色。

项目分类之间留白 8px，分类标题与首条群聊间距 4px；群及子区行距保持原样，不增加分隔线或底色。

关注／最近保持圆形胶囊，白色选中块采用 220ms 平滑位移，减少动态效果设置下关闭过渡。拖拽分类或大群只应用位移，禁止缩放导致群及子区压扁。滚动条保持原样。

## 子区关注与创建命名

- 子区不提供“关注”入口；关注用于项目／大群的关注视图。子区通过置顶、免打扰及生命周期整理，不形成“关注里的关注”。
- 创建表单统一使用“子区名称”和“输入子区名称”，名称最多 30 个字符。

## 2026-09-20 项目切换器下拉分组

- 顶部项目切换器下拉复用成员仓库的账号级项目置顶列表，与「我的消息」关注、项目目录「关注项目」同一数据源，不新增状态；按钮样式沿用 035 现有切换器 CSS。
- 仅当「既有关注项目、又有未关注项目」时分两个分组：「关注项目」在上，「未关注项目」在下，中间一条分隔线；已关注项目不在下方重复出现。
- 全部关注或没有关注项目时维持平铺，不显示分组标题，也不出现空分组。
- 工具栏「全部项目」按钮仍是进入项目目录的图标按钮，不与该下拉分组名称共用含义。
- 默认关注固定为随包演示的 4 个项目：供应链运营协同、客户联合交付、EVA Official Space、团队文件功能设计。之后新加进演示数据或用户新建的项目默认不关注，只出现在「未关注项目」，需在项目目录手动关注。
- 初始化只补齐默认关注，不覆盖个人已保存的关注：用户取消关注或新增关注后刷新仍保持个人选择。
