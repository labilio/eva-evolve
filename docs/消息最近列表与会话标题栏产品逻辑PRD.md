# 消息「最近」列表与会话标题栏产品逻辑 PRD

- 版本：v1.0（现状描述稿，2026-09-21）
- 适用范围：团队「消息」页的「最近」会话列表、团队 IM 会话页标题栏
- 参考页面：`/messages`（消息－关注/最近）、`/messages` 右侧会话流
- 文档性质：对当前已实现产品逻辑的整理，不含新增需求

---

## 1. 「最近」列表定位

「最近」回答"我最近和谁有往来"，是按活动时间自动排列的**扁平会话流水**，不做业务分组。业务分组职责由「关注」tab 承担，两者数据同源、视图独立。

## 2. 会话范围

| 会话类型 | 是否进入「最近」 | 说明 |
| --- | --- | --- |
| 项目群聊 | 是 | 我有权限看到的所属项目群 |
| 同事私聊 | 是 | DM 会话 |
| 其他/演示类会话 | 是 | 归入"其他"类目的团队会话 |
| 子区 | 是（独立一行） | 有活动的子区作为独立会话对象出现，有自己的时间与摘要 |
| 被静音的会话 | 是 | 仍在列表中，但不显示未读数（静音 = 不打扰，不等于隐藏） |

## 3. 排序规则

1. **置顶优先**：我手动置顶的会话固定排最前（详见 §4）。
2. **时间倒序**：其余按最近活动时间倒序——群聊取群内最新消息时间，子区取子区最新消息时间；谁有新动态谁上浮。
3. **搜索态例外**：搜索时不按置顶排序，直接按匹配结果的时间排序。

## 4. 置顶逻辑

### 4.1 入口

- 最近列表会话行**右键菜单** →「置顶会话 / 取消置顶」。
- 子区另有独立的「置顶子区」个人开关，入口共三处：子区列表下拉、子区侧栏菜单、子区信息面板开关。

### 4.2 规则

| 规则项 | 说明 |
| --- | --- |
| 归属 | 个人偏好，按账号记忆（浏览器本地存储），换账号互不影响，他人不可见 |
| 数量上限 | 无 |
| 作用范围 | 仅影响「最近」tab 的排序与样式；「关注」tab 使用独立的分组拖拽排序，不吃置顶 |
| 排序 | 置顶会话排最前，置顶区内部仍按时间倒序 |
| 视觉 | 置顶行整行灰色底；相邻置顶行连成一整片灰底区域，与普通行明确区分 |

## 5. 头像逻辑

头像由会话对象身份决定，全项目统一一个头像数据源，业务入口不自行拼接：

| 对象类型 | 头像规则 |
| --- | --- |
| 私聊（真人） | 对方个人头像；未设置时自动生成图形头像（非首字母） |
| 群聊 | 群自定义头像优先；无自定义时用所属项目的项目色生成群图形；无项目归属用中性默认图形 |
| AI 会话 | 直接使用该 AI 身份头像（分身/助理的合成头像），与通讯录等其他入口完全一致 |
| 子区行 | 头像即父群头像，**不**在角上叠加"子区"小角标；子区身份由名称前小图标表达 |

## 6. 列表行两行展示逻辑

每行固定两行结构，不允许出现第三行：

| 行 | 左侧 | 右侧 |
| --- | --- | --- |
| 第一行 | 会话名称；子区名称前带子区小图标 | 最后消息时间（今天显示时刻，更早显示日期） |
| 第二行 | 最后一条消息摘要：文本直接显示；文件/引用/任务卡等显示「[文件] xxx」等类型前缀 | 提醒徽标：「@我」优先显示，否则未读数字（>99 显示 99+） |

**路径提示**：会话所属项目/群路径不再单独占行（旧版第三行已删除），改为悬停名称时以 tooltip 显示「完整路径 / 名称」。

## 7. 会话页标题栏逻辑

### 7.1 标题显示

| 场景 | 标题规则 |
| --- | --- |
| 群聊 | 群头像 + 群名 |
| 子区 | 面包屑「父群名 › 子区名」；**父群名可点击，点击返回父群**；子区名不可点 |
| AI 会话 | 身份名后紧跟 AI 标；名称按身份类型自动生成（如项目管理专员显示「项目全名 · 项目管家」），标题栏不可改名 |
| 个人助理对话 | 只显示助理身份名，不暴露底层两人群/子区名 |

### 7.2 右侧操作按钮（从左到右）

| 按钮 | 显示条件 | 行为 | 激活态 |
| --- | --- | --- | --- |
| 项目跳转（项目图标＋项目名） | 仅项目群/子区 | 在会话内打开该项目的内容面板，不离开当前聊天 | — |
| 搜索 | 始终 | 右侧展开「查找聊天内容」面板，再点收起 | 有高亮 |
| 子区 | 仅父群视图（进入子区后隐藏） | 切换右侧子区列表面板，再点收起 | 有高亮 |
| 「⋯」信息 | 始终 | 打开信息面板：父群为「聊天信息」，子区为「子区信息」 | 有高亮 |

**「所属项目」行的一致性**：聊天信息面板中的「所属项目」行与标题栏项目按钮行为一致——点击在当前页面内打开该项目的内容面板，不整页跳转。**项目上下文收口**：项目跳转入口只在「会话所属项目 ≠ 当前所在项目上下文」时出现。消息页打开项目群或项目子区时显示标题栏按钮、信息行可点；在项目 - 群聊页签内打开本项目群/子区时（已在项目内），标题栏项目按钮与群聊/子区设置页的「所属项目」行**全部隐藏不可见**。项目内不可能打开其他项目的会话。

### 7.3 边界

- 标题栏本身不提供搜索入口以外的内容搜索（搜索是右侧面板功能）。
- 本标题栏属于团队消息体系；个人 Eva 页面使用独立的头部体验，两者不混用。

## 8. 验收要点

1. 置顶：右键置顶后行置灰并排最前；取消置顶恢复时间序；换账号置顶互不可见；关注 tab 不受影响。
2. 头像：同一 AI 会话在列表与通讯录头像一致；子区行头像与父群相同且无角标。
3. 两行结构：任意会话行不出现第三行；路径仅 tooltip 可见；徽标「@我」优先于未读数。
4. 标题栏：子区中父群名可点击返回；子区按钮仅在父群显示；四个按钮激活高亮正确。
