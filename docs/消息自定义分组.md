# 消息自定义分组

2026-09-08 用户确认：消息顶部「+」提供「创建分组」，Category 用于非项目会话分类，现有「其他会话」属于同一类可自定义分组。

- 「+」保留「新建群聊」，新增「创建分组」。名称必填，1–50 字符，同一用户不能重名。
- 创建时可选非项目会话；分类标题右侧「…」可编辑名称和会话归属，包括「其他会话」。空分类也可显示，之后再添加会话。创建与编辑复用同一表单，选择会话时使用拉人模板 A 的双栏多选形态（搜索、已选栏、会话身份头像），不再使用自写复选列表。
- Category 是个人整理视图，不创建项目或群，不更改群名、成员与访问权限。项目群及子区始终由项目归属决定，不可移入用户分类。
- 分类和会话分配由 membership store 按用户保存；刷新后恢复。未指定分类的非项目会话回到默认分类（初始名称「其他会话」）。分类及分类内的原有排序能力继续复用。
- 浏览器验收示例：创建「日常协作」，将高志远私聊移入，再改名「工作交流」。示例保留在本地预览。创建与编辑复用同一表单，消息流与输入保持共用实现。
