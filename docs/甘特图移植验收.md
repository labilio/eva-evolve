# Plane 甘特图移植：实施与验收

状态：本轮实现、主验收、双角色独立试用及反馈修正完成。2026-10-15 用户明确同意将当前版本合并 main，后续体验优化另行继续。

下方按时间保留排查记录，历史“待检查/失败”以文末最新结果为准。

## 目标与来源

将甘特图接入 Eva 项目任务第四种视图。看板、表格、层级、甘特图共用任务集合、稳定 ID、筛选、更新事务、身份规则、详情和创建入口；不引入 Plane 的独立任务存储或权限模型。

来源为 Plane v1.4.2（5f7d92784c403f76284f0f16718f320221dc7fec）。先读代码确认规则，再用原产品页面核对视觉；不得根据截图推断业务。

- `apps/web/core/components/gantt-chart/data/index.ts`：周／月／季度日宽 60／20／5。
- `gantt-chart/constants.ts`：44px 行、48px 表头、40px 工具栏、360px 左列、60px 单日期任务条。
- `gantt-chart/views/helpers.ts`：截止日包含当天，无日期不计算任务条。
- `gantt-chart/helpers/blockResizables/use-gantt-resizable.ts` 与 `core/store/timeline/base-timeline.store.ts`：整条移动、左右边界调整；只在拖动缺失边界时补齐该日期。
- `gantt-chart/blocks/block-row.tsx`：视口外任务定位与无排期任务。
- `gantt-chart/helpers/add-block.tsx`：点击空排期位置设置日期；周／月默认跨两天，季度跨八天（均包含起止日）。
- `gantt-chart/sidebar/utils.ts`：独立于状态的手动行排序。
- `gantt-chart/chart/header.tsx`：Lucide Expand／Shrink，周／月／季度、今天、全屏。

本地实现为 Eva 的适配实现，不引入 Plane MobX/Next 运行时。不扩展社区版没有的关键路径、依赖自动调度、工作日历或里程碑对象。

## 用户已确认的中国用户适配

- 周一为每周起点，周日位于末尾；公共任务日期面板与时间轴一致。
- 中文年月日与控件文案；任务日期按自然日计算，不提供夏令时概念或其他地区专属设置。
- 不自动跳过周末，也不自行引入节假日、调休和工作日排期。
- 业务图标使用 Lucide，Semi 组件内置关闭／警告等图标保留。
- 优先复用现有业务组件，再选择合适的 Semi 能力；不为使用标准组件而破坏专用甘特布局。

## 交互状态设计：通用检查框架

这属于交互逻辑，工程上由 UI 状态管理、状态转换和业务规则共同实现；不是一个可安装组件包。产品设计负责确定行为，前端负责呈现与本地交互，数据层负责业务记录和写入合法性。原型目前是共享业务适配加浏览器本地状态，不冒充后端多人同步。

每项记录“触发事件 → 前置条件 → 下一状态 → 反馈 → 保存位置 → 重置边界 → 失败恢复”，并注明 Plane 源码依据或 Eva 适配决定。

| 检查类别 | 甘特图需要回答的问题 | 当前责任边界 |
| --- | --- | --- |
| 初始化与默认 | 首次尺度、今天来源、新建日期、无日期任务 | 视图初始化及共享创建配置 |
| 上下文与恢复 | 返回视图、项目/范围/筛选切换、刷新、全屏 | IssuePage 上下文内记忆；刷新不恢复精确位置 |
| 输入与反馈 | 悬停、焦点、选中、拖拽预览、禁用、保存中 | 共享控件与甘特局部暂态 |
| 操作完成与中断 | 确认、取消、Escape、指针取消、页面卸载 | 预览不直接写业务记录，提交后共享刷新 |
| 数据边界 | 空项目、筛选无结果、缺一个日期、同日、跨月/闰年 | 统一日期规则与共享空状态 |
| 异步与冲突 | 保存失败、迟到返回、拖动期间记录被更新 | 共享写入接口、旧快照检查、卸载后反馈抑制 |
| 权限与可用性 | 只读、权限撤回、重复提交 | 界面禁用与业务写入校验同时执行 |
| 导航与层级 | 打开详情、返回、子弹层、焦点归还 | 统一详情及公共浮层合同 |
| 可访问与地区 | 键盘、完整名称、中文、周一、自然日 | 公共控件和日期工具，不引入地区专属排期 |
| 布局与规模 | 短条、长标题、窄窗口、明暗、长时间轴、大列表 | 可视区渲染、公共 token、预览与固定左列 |

这里的“完整”指本轮已确认能力的状态闭环，不表示自动加入依赖调度、资源管理、撤销历史或离线同步等新产品能力。没有实现的能力不能靠通用术语暗示存在。

### 共享日期写入校验

- Plane v1.4.2 的 `apps/api/plane/app/serializers/issue.py` 与 `api/serializers/issue.py` 拒绝开始日期晚于截止日期。Eva 在共享 `updateIssue` 写入前调用 `EvaTaskTime.scheduleError`，校验原任务与本次修改合并后的区间，因此只改一个日期也会校验另一端。
- 拒绝不存在的自然日、时间戳字符串与倒置区间；允许同日排期、单日期与清空。空值统一为 null。失败前不改任务、活动记录或更新时间；非日期更新不强制修复历史排期。
- 甘特图和表格沿用共同 Toast 错误提示；移除了甘特图重复的页面内错误横条，避免错误提示挤动时间轴。

### 同一任务页内的视图位置记忆

- 所有者是 IssuePage 的 `evaGanttViewMemory`，与既有看板位置记忆处于同一层；不新增 window 全局、DOM 状态仓库或第二份任务数据。
- 账号、项目、任务范围和筛选条件共同组成键。记录尺度、左侧可见日期及日内像素比例、顶部任务稳定 ID 和行内偏移；返回时按当前任务集合解析，任务已不存在则回退到合法行范围。
