# 表单与操作区统一规范

本规范适用于 Eva 自有的“填写或选择信息后确认保存”界面。一个输入框也可以是表单。搜索、筛选、即时设置、聊天输入区和无字段确认框不因为含有控件就成为提交表单。自动化及独立批注工具不在本次表单迁移范围内。

## 唯一入口与职责

- `063-forms-entry.jsx` 是业务唯一接入入口，构建为 `eva-forms.module.js`；通过 `createForms(React, ReactDOM)` 复用现有渲染器。运行时依赖以 `forms`/`evaForms` 注入，不新增 React 根节点、第二份 Semi 配置或页面级表单框架。
- 普通字段使用原生 `Form.Input`、`Form.TextArea`、`Form.Select`。复杂成员、任务属性、附件和标签等业务选择器复用现有业务组件，用 Form 值或 `withField` 接入，不重写身份、权限或数据事务。
- 原生 Semi Form 管理字段值、规则和字段错误；公共 `useSubmission` 管理提交时机、串行校验、防重复提交、首次错误聚焦和关闭/重开隔离。页面只提供业务字段、规则和保存动作。
- Semi 全局默认配置只在 `063-forms.jsx` 设置，且仅影响该共享实例。旧运行时里的 Semi 不会自动获得新配置；迁移入口必须显式接入公共模块。

## 统一行为

1. 必填未完成不禁用确认按钮；点击确认后显示字段下方的原生错误提示，并定位首个错误。首次提交前不因空值提前满屏报错；报错后修改会重验。
2. `useSubmission` 覆盖校验到保存的完整提交锁。普通单行 Enter 提交，多行 Enter 换行，中文输入法组词 Enter 不提交。Portal 子表单不得触发父表单提交。
3. 输入值转换用原生 `convert`，不在同一字段 onChange 再 setValue。Select 值须在立即提交前生效，共享实例使用 `motion:false`，不能在业务层靠延迟保存补救。
4. 字段错误由 Semi 呈现；保存失败由公共 `SubmissionError` 展示。文件解析等尚未形成可提交字段的数据处理错误可由专用业务组件表达。不要为每个页面再建 touched/invalid/error 校验状态。
5. 关闭或切换业务对象须重置当前提交生命周期。异步保存后的 UI 更新、导航、关闭和成功回调先检查 `isCurrent()`。关闭界面不会撤销已经发出的保存操作。
6. 提交中的按钮可 loading；取消、关闭按钮和遮罩关闭仍可用。权限不足、缺少合法业务范围等非“字段未填写”原因可以禁用操作，并给出可理解的说明。
7. label/id 必须对应。使用纯字段布局时保留可访问名；Semi Select 的外部标签使用 `{id}-label`，不能只假定 aria-label 会覆盖组件生成的标签。

## 弹窗和按钮区

- 已迁移的普通表单弹窗使用公共 `Dialog`，双按钮操作区使用 `Actions`，两者底层直接使用 Semi Modal/Button。Semi 没有独立 Form.Button。
- 普通弹窗外壳统一20px左右留白，正文24px上下留白；标题区最小48px、长标题可增高，标题下方和页脚上方各1px分割线，页脚16px上下留白；按钮右对齐，间距12px，取消在左（tertiary/light），主操作在右（primary/solid），危险操作用 danger/solid。按钮无需业务页面重写颜色。
- 宽度用 compact（420）、standard（480）、wide（680）等语义变体；任务 compose（600）、带预览技能 preview（760）、助理 editor（920）保留已确认的复杂内容构成。不能把所有内容强制塞进一种宽度。
- 弹窗标题16px/500/25.144px，正文与按钮14px/400/22px，分组标题14px/500/22px，辅助说明12px/400/18px。颜色、圆角、字体家族和业务布局沿用Eva。参数集中在 `063-dialog-theme.js`；构建器用锁定版本的Semi官方Modal Sass变量生成差异主题；`063-dialog.css`只处理宿主、滚动和操作区集成。旧页面不得用局部 CSS 覆盖公共间距和错误色来制造新变体。
- 点弹窗外内容区空白关闭，原生 `maskClosable`/`onCancel` 承担这件事；不是输入框 blur 或应用失焦。嵌套 Select/Dropdown 不关闭父弹窗。自定义浮层沿用 `EvaPopupDismiss`，见《弹窗失焦关闭规范》。
- 身份资料卡、文件预览、复杂设置工作区等不是普通提交表单，不为了本次迁移重构其内容或导航；其外部点击规则同样须符合现行规范。

## 业务状态与例外

查询词、弹窗打开对象、编辑页签、解析中状态、专用业务选择器展开状态不是重复字段校验状态。创建项目不提供任务前缀字段；保存时由公共前缀规则自动生成并处理重名。已有项目的前缀管理继续位于项目设置。技能包解析、外部链接更换域名确认保留业务流程，不把提示当作通用必填规则。

## 防回退与验收

`tests/form-policy.test.mjs` 和 `tests/form-architecture.test.mjs` 守住共享策略与入口；真实 Semi 行为在 `tests/browser/*form*.mjs` 验收。至少覆盖空提交、修正、重复提交、关闭重开、Portal 子表单、异步迟到结果；每个业务入口还须验证原数据保存、权限和重新读取。视觉核对使用同一视口下的前后截图，区分授权的外壳/按钮变化与需保留的内容排版。

新增或迁移入口必须更新本表、补业务适用的回归；不可用全局 CSS 伪装错误态，也不可通过移除业务断言让测试通过。用户亲自测试并明确同意前，不合并 main。

## 校验提示文案

“请输入名称”“请填写任务标题”等简短单句校验提示不加句末句号；多句说明保留必要标点。不通过全局字符串替换删除正文标点。

## 错误提示视觉

字段错误使用 Semi Form 原生 ErrorMessage，不覆盖字号、行高、字体、错误色或提示间距。当前锁定版本的默认值为 14px / 20px、`--semi-color-danger`、顶部间距 4px；以组件版本和公共主题为准，不在业务 CSS 复制数值。提示位于对应字段下方并与控件对齐；内容留白在字段容器处理。

提交失败和文件解析等业务错误通过公共 `SubmissionError` 调用原生 `Form.ErrorMessage`，由外层 `role="alert"` 提供播报。页面不借用内部样式类手工造错误元素。灰色说明、空状态和页面级加载错误保留各自语义，不混入字段错误。

## 键盘焦点

依据 [W3C APG Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)，公共 Dialog 通过 Semi `modalRender` 接入一次初始焦点：填写型优先输入框，选择型优先选择器，重命名选中原名称，危险确认优先取消，结构化阅读内容显式 `initialFocus="title"`。Tab 循环沿用 Semi；公共适配补齐静态标题反向 Tab、嵌套 Escape 和入口消失后的返回位置。关闭默认回到打开入口；入口会消失的业务传 `returnFocus` 指定后续逻辑入口。业务不再追加延时 focus、Observer 或第二套焦点陷阱。

Semi 2.103.0 没有 initialFocus 参数，不能把上述公共适配描述成组件开箱自带。对话框标题ID每实例唯一，复杂表单不把整段内容绑定成 aria-describedby。

## 必填标记与校验分离

星号用于区分同一表单中的必填与选填项：混合表单只给必填字段显示 Semi 原生星号；单字段重命名、全部必填或全部选填的简单表单不显示星号。隐藏星号不取消必填校验。公共 `requiredLabelPolicy` 根据业务字段的 required 声明生成 Semi label 参数，成员选择的必填性从 minimumSelection 推导；不手绘星号，不用 CSS 隐藏标记。搜索和筛选不是提交字段，不参与判断。

标准弹窗正文直接承载 Form 时，正文负责外侧留白，首尾字段不叠加 Semi 默认的上下 padding；字段之间的间距仍沿用 Semi。规则统一放在公共 Dialog 集成样式中，复杂任务及助理编辑器不受此规则影响。

间距回归见 `tests/browser/dialog-form-spacing.mjs`：覆盖14个真实标准弹窗场景，验证正文留白与由布局容器管理的字段间距不重复；任务、助理编辑器保留独立内容结构，不套用全局清零。


远端整合时保留现行 GROUP.md 编辑器的编辑/预览、字节限制和删除能力；它尚未重新迁移为公共 Form，不以旧版简化编辑器覆盖这些能力。连接中心不属于本轮迁移成果。

字段标签使用公共 `dialogText.fieldLabel`（14px / 500 / 22px），由主题构建生成并限制在公共提交表单内。不要在单个字段或业务页面重复指定字重；错误提示、选填辅助说明继续使用各自原生样式。
