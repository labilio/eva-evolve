# 身份头像更换与圆形裁切编辑器规则

配套 AGENTS.md「AI 身份统一规则」（自该文件下沉，与其同效）。修改任何头像上传入口前先阅读本文件。

## 可更换范围与入口

- 人类本人、分身主人和个人助理主人可更换头像；数字员工与项目管家头像固定、不提供更换入口。上传入口不提供预设或程序生成的头像。
- 资料卡入口常态不可见（弹窗自动聚焦也不触发），仅鼠标悬停或键盘聚焦时头像整圆浮出灰色蒙版与居中相机。
- 入口共三个：本人／分身／个人助理的身份资料卡点击头像；侧栏底部账号菜单的「更换头像」（仅本人，直接打开同一个资料卡编辑器，保存后关闭资料卡；菜单仍保留设置与退出登录）；群头像选择本地图片。分身与个人助理只从各自身份资料卡进入；个人助理还可在 AI 小队共享编辑器自选 emoji／图标替换主图。

## 同一个圆形裁切编辑器

- 所有上传本地头像图片的入口都先进入同一个圆形裁切编辑器确认后写回，取消不改变头像：中部 112 px 圆形舞台，可缩放拖拽；裁剪页页脚提供「取消 / 保存」，保存写回并回到资料卡身份页，取消放弃本次裁剪。
- 编辑器不提供「恢复默认」；仅群头像保留「恢复默认头像」。侧栏账号菜单形态常态只有头部与圆形舞台，提示「点击头像上传图片，不超过 5 MB」；关闭入口为顶部关闭按钮、Esc、遮罩与「取消」，没有常驻页脚、第二个关闭控件、第二个标题、重复说明或返回按钮。
- 编辑器与圆形裁切集中在 `prototype/009-3-identity-card.js` 与 `prototype/060-avatar-editor.css`，并以 `AvatarEditor`／`readAvatarFile` 供 `prototype/009-2-chat-settings.js` 的群头像入口复用，禁止另写第二套裁切；资料卡宿主固定挂到 `document.body`，允许从侧栏打开而不被内容区层叠压住。

## 数据源与写入边界

- 头像数据是唯一数据源：人类写入成员档案 `avatar`，分身在主人档案下写入 `state.clones[].avatar`，个人助理写入 `EvaAITeam` 的 `configuration.avatar`，并统一经 `window.EvaAIIdentity.avatar` 渲染。
- 姓名不通过头像入口修改；写入只允许本人账号，非法图片数据一律拒绝。
- 云端分身与个人助理的默认主图均为 Eva Logo，不随主人更换头像变化；历史数据把 Logo 存为自定义主图时按未自定义处理，仍渲染默认 Eva Logo。
- 只开放头像编辑：替换头像只能再次上传（无「恢复默认」兜底）；姓名等其余资料仍不可改（旧「不增加资料编辑」口径自此仅限头像放开）。
