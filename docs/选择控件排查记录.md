# 选择控件排查记录（2026-10-09）

本轮针对下拉菜单的无意义前置缩进、缺少身份/业务图形、选中回填与旧项目候选残留。不是功能重设计；搜索范围、权限、数据写入与单选/多选语义沿用各入口。项目自动化的旧“发送到”按用户决定直接删除，不创建替代目标选择器。

## 根因与公共合同

- 业务直接使用 Semi Select 默认选项布局，默认勾选槽与 Eva 菜单的布局不同；部分入口仅传文字，公共头像、状态、优先级和标签未接入。
- 公共适配 `prototype/004-select-controls.js` 负责呈现，Semi 保留选中、搜索、清空和键盘行为。图形在前、勾选在后；不占空白勾选槽。
- 选项图形通过 `icon`，纯文本检索名通过 `label`，复杂业务内容通过 `content`；候选与回填复用同一身份组件。
- 菜单皮肤位于 `049-gds-brand-reroot.css`。Select 行铺满弹层可用宽度，不继承 Dropdown 的 280px 最大宽度；不套用 Dropdown 外壳动画 class。
- 已移除任务专用选项适配器，避免两份实现。
- 双层外壳根因：原全局 CSS 同时装饰 Popover 外壳和选项列表，且列表外套保留默认 4px 留白。删除内层背景/圆角规则，外壳统一为实色公共浮层，列表外套留白归零；浏览器回归检查唯一表面。

## 全量源码入口检查

| 入口 | 处理 |
| --- | --- |
| 任务筛选：状态、优先级、负责人、创建者、标签、时间字段 | 使用公共适配；保留既有业务图形与项目候选边界 |
| 任务批量状态、优先级 | 接入公共适配并补齐公共图形；优先级无、紧急、高、中、低 |
| 父任务选择及任务详情父任务 | 公共适配；保留原搜索和排除自身规则 |
| 项目自动化创建及详情 | 删除旧“发送到”字段、候选 state、加载请求、写入字段 |
| 自动化每周计划 | 公共适配；周一至周日排序，保留原星期值，计划状态与摘要同步 |
| 专家运行时、专家团负责人和成员 | 公共适配；人员选项及回填使用公共身份组件 |
| 成员 UI：演示身份、项目角色成员、多选角色、遗留接任选项 | 经组件依赖注入统一接入；保留权限规则 |
| 成员 UI：目标文件库与文件夹、选择器预览筛选 | 经组件依赖注入统一接入 |
| 数字员工配置枚举 | 经组件依赖注入统一接入 |
| Semi 分页内部的每页条数 | 第三方内部控件，不改其实现 |
| 原生 select：文件库/项目文件的目标库与文件夹、连接中心认证/传输、个人 Eva 文件夹、外观主题、项目里程碑状态 | 源码检查；不使用 Semi 勾选槽，不批量替换原生交互 |
| 既有 AssigneePicker、成员选择器、模型选择器和 Dropdown | 沿用各自公共业务组件，不另造 Select 版本 |

构建产物不再引用 `listProjectOptions`。任务页已下线项目筛选对应的候选加载也已删除。旧 `PROJECTS` 数据的其他业务用途不在本轮选择控件删除范围内。

## 验证边界

- 单元合同：`tests/select-controls.test.mjs`，验证公共适配、禁用行为、事件委托及单/多选回填。
- 浏览器：`npm run test:select`，验证自动化创建/详情无旧项目字段、每周选择回填、菜单缩进及铺满宽度、成员头像、角色多选、页面往返及无脚本错误。
- 任务回归：`npm run test:task-table`，覆盖表格及筛选业务图形、身份、中文搜索、键盘选择和清空。
- 其余入口已做源码装配审计，不将共用组件回归等同于每个入口都完成人工验收。人工验收与 main 合并仍由用户决定。

本轮执行结果：508 项单元测试通过，任务表格/筛选 2 项及公共 Select 浏览器回归通过。搜索回归 19/20；外部资源弹窗首次焦点失败。成员选择器模板回归在全员群说明文案处超时。这两处失败均在重新构建的 main 上复现，未修改测试放宽条件，也未将它们标为通过。

## 双层外壳源码复查

对照 `prototype/*.css`、`vendor/eva-legacy.css`、模块源码及构建后的组件装配，检查表面归属（不是只按圆角关键词判断）：

| 组件族/入口 | 源码结论 |
| --- | --- |
| 所有 Semi Select（任务筛选、成员角色、计划星期、专家配置等） | 原 `048` 全局列表背景规则会传播到这些入口；已统一删除，外层 Popover 是唯一表面 |
| 任务筛选面板/显示设置、人员 Dropdown、枚举 Dropdown | 内部 `.loop-fields`、菜单列表只布局；表面由 Dropdown wrapper 持有，无重复背景和投影 |
| DatePicker 日历 | 内部 container 无背景/投影；外层 Popover 持有表面；年月滚动列表明确去掉阴影 |
| TimePicker 时间/时间范围 | 使用自己的 `prefixCls`，不会命中 `.semi-popover-wrapper` 的玻璃表面；单时间由 ScrollList 持有表面，范围列表显式去掉子 ScrollList 阴影 |
| 模型 AutoComplete | option-list 只定义滚动，外层 Popover 持有表面 |
| 表格列/分组/导出/表头菜单 | 菜单本体有表面，`062-loop-table-view.css` 已显式清空外层 Popover 背景、圆角、投影和模糊 |
| 新建任务标签菜单 | 菜单本体有表面，`049-loop-task-create.css` 已显式清空外层 Popover 装饰 |
| 技能使用者提示、分页更多页码 Popover | 内容只布局，无第二层背景和投影 |

除已修复的 Select 全局规则外，本次源码检查未确认新的同类双层底板。此结论仅限上述组件装配和样式规则，不等同于全产品逐页视觉验收；本次复查未新增产品代码修改。
