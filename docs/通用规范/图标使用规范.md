# 通用：图标规则

版本：v0.1，2026-09-15。适用于 Eva 各业务菜单的功能图标。只记录选型与语义，不规定尺寸、线宽、点击热区或交互状态。

## 已定规则

1. 功能图标统一使用既有 Lucide 组件与语义，不混用另一套图标库。
2. 同一语义优先复用同一图标。图标可以在多个入口重复使用，没有“每个图标只能出现一次”的限制。
3. 保留已经确认的图标含义，不因常见产品采用其他图标而自行更换。不同语义只有在确实造成识别混淆时才调整。
4. 不以手写 SVG、Unicode 字符、Emoji 或 CSS 图形替代已有 Lucide 功能图标。Lucide 组件本身输出 SVG 不受此限制。
5. 所需图标未在当前组件包导出时，通过公共适配层接入官方节点定义，不由业务页面分别重画。
6. 品牌 Logo、用户头像及已确认的身份素材不属于普通功能图标，不强制替换成 Lucide。
7. AI 标不是功能图标，也不是连接状态标；按[联系人与 AI 身份展示规范](./联系人与AI身份展示规范.md)处理。

## 已确认的部分映射

| 语义或入口 | 图标 | 限定 |
| --- | --- | --- |
| 搜索 | Search | 不因图标统一而新增搜索能力 |
| 聊天任务 | ClipboardList | 打开所属项目任务，不表示个人待办 |
| 常规添加／新建 | Plus | 个人 Eva 新对话保留既有铅笔语义 |
| 子区 | CornerDownRight | 层级列表与创建消息使用同一语义；消息右键菜单的创建入口使用 MessageSquarePlus |
| 项目归属、项目文件库 | LayoutGrid | 配色来自项目身份，不按名称猜测 |
| 更多操作 | Ellipsis | 不用文字省略号模拟 |
| 设置 | Settings | 只用于真实设置操作 |
| 数字员工默认头像 | 既有 Bot 素材 | 仍作为头像读取与展示，不是操作按钮 |

未列出的现有图标沿用已确认映射，本表不是新增功能清单。“我的 AI”等已确认的专用素材继续保留，不借统一 Lucide 更换。
