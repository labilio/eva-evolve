# 通用：布局规范

版本：v0.2，2026-09-22。规定页面与附属内容的呈现关系、共同外壳和覆盖范围，包含已确认的公共外壳尺寸，不扩展未确定的页面细节或动效。

## 1. 三种呈现方式

| 类型 | 定义 |
| --- | --- |
| 右侧覆盖面板 | 从所属内容区右侧打开，覆盖该区域的一部分；原聊天页不缩窄、不重新排版 |
| 右侧并排预览 | 与当前内容并排，占用其可用宽度，当前内容随之缩窄 |
| 模态弹窗 | 在当前页面之上完成创建、选择或确认，不替换页面，不占用页面布局宽度 |

不能只因都位于右侧就共用一种挤占方式；是否挤占由下表决定。

## 2. 已确认场景

| 场景 | 形态 | 是否挤占原内容 |
| --- | --- | --- |
| 群聊中打开任务列表／任务详情 | 右侧覆盖面板 | 不挤占聊天页 |
| 群聊中打开子区列表／子区侧栏 | 右侧覆盖面板 | 不挤占聊天页 |
| 聊天右上角三个点打开聊天信息、子区信息 | 右侧覆盖面板 | 不挤占聊天页 |
| 消息、项目文件、文件库打开文件预览 | 右侧并排预览 | 挤占当前内容区 |
| 任务详情内打开附件预览 | 工作区全屏覆盖层（铺满工作区内容区） | 覆盖看板与任务详情，保留顶栏项目页签与最左全局导航，不挤占任务详情 |
| 创建任务 | 模态弹窗 | 不挤占，不以跳转项目页替代会话入口 |
| 批量添加成员、新建群聊／AI 小队 | 模态弹窗 | 不挤占；使用下述共同拉人形态 |
| 文件信息、身份资料 | 居中弹窗 | 不冒充文件内容预览 |
| 退出／解散等需确认的操作 | 确认弹窗 | 不以一级页面承载确认 |

子区在主会话区域完整打开时仍属于当前会话，不要求任何子区访问都打开侧栏。表格中的“子区侧栏”是附属打开方式。

## 3. 共同外壳与状态边界

- Eva 是桌面客户端。系统标题栏全局唯一且持续可见，业务页面、右侧面板与默认遮罩位于其下方，不重造或遮挡系统标题栏。
- 聊天任务、子区、聊天信息和子区信息共用右侧面板的 52px 标题栏、24px 左右内边距、内容区与右侧关闭位置，不为各入口建立另一套外壳风格。
- 抽屉族外壳（右侧覆盖面板统称，含任务详情抽屉、聊天任务、查找聊天内容、线程面板）统一分层与外观，只允许一种写法：分层用「方向性投影 + 左缘 0.5px hairline」（token `--eva-shadow-drawer`，暗色自动加深），不使用实色 border-left；表面用 `--eva-surface-primary`；标题栏 52px/24px，标题 16px/600；关闭等头部图标按钮 32×32、圆角 8、悬停填充 `--eva-overlay-hover`；宽度两档——标准抽屉 380px，任务详情抽屉 clamp(640px, 70%, 900px)。实现由 `prototype/062-drawer-contract.css` 与 `047/057` token 层维护，新增右滑面板必须消费同一契约，不得再定义独立投影或边线。
- 文件预览保持同一套内容工具与全屏能力；全屏仅覆盖系统标题栏下方、最左侧全局导航右侧的工作区，最左导航保留。退出全屏恢复原并排宽度。
- 打开聊天信息不重建聊天流或输入区，保留当前草稿与滚动位置。关闭附属面板后仍回到所属对象，不残留其他会话的内容。
- 一级页面只替换客户端内容区，个人 Eva 和团队 IM 继续保持各自业务形态；布局统一不合并它们的历史或数据。

## 4. 拉人模板 A：共同外壳与入口

项目、群聊和 AI 小队共用 `EvaMembersUI.MemberPicker`，按业务配置选择创建形态或纯拉人形态，不复制选择器 DOM、CSS 或事件。

- 创建形态包括业务字段与双栏选择区；纯拉人形态不保留不存在的名称字段或标签留白。
- 两侧列表独立滚动，标题与页脚固定；弹窗位于客户端系统标题栏下方。
- 公共模板拥有尺寸、留白和按钮交互态，业务宿主不得覆盖。具体参数、分类、默认预选、提交校验和空状态统一维护于[拉人模板 A](../拉人模板A产品与前端规范.md)，本文件不重复保存数值或默认状态。
- [八类业务入口与共用关系](../拉人模板A产品与前端规范.md#21-八类业务入口与共用关系2026-10-15)区分新建／添加项目、项目／非项目群及新建／编辑 AI 小队。项目群联系人须先入项目；全员群、子区不提供拉人入口，默认 AI 小队不手动维护成员。
- 候选与已选身份遵循[身份展示规范](./联系人与AI身份展示规范.md)。项目／群资格与事务读[我的项目](../专项规范/我的项目.md)，群入口读[我的消息](../专项规范/我的消息.md)，AI 小队读[我的 AI](../专项规范/我的AI.md)。
