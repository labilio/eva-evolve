# 通用：布局规范

版本：v0.1，2026-09-15。规定页面与附属内容的呈现关系、共同外壳和覆盖范围，包含已确认的公共外壳尺寸，不扩展未确定的页面细节或动效。

## 1. 三种呈现方式

| 类型 | 定义 |
| --- | --- |
| 右侧覆盖面板 | 从所属内容区右侧打开，覆盖该区域的一部分；原聊天页不缩窄、不重新排版 |
| 右侧并排预览 | 与当前内容并排，占用其可用宽度，当前内容随之缩窄 |
| 模态弹窗 | 在当前页面之上完成创建、选择或确认，不替换页面，不占用页面布局宽度 |

不能只因都位于右侧就共用一种挤占方式；是否挤占由下表决定。

## 2. 已确认场景

| 场景 | 形态 | 是否挤占原内容 |
| --- | --- | --- |
| 群聊中打开任务列表／任务详情 | 右侧覆盖面板 | 不挤占聊天页 |
| 群聊中打开子区列表／子区侧栏 | 右侧覆盖面板 | 不挤占聊天页 |
| 聊天右上角三个点打开聊天信息、子区信息 | 右侧覆盖面板 | 不挤占聊天页 |
| 消息、项目文件、文件库打开文件预览 | 右侧并排预览 | 挤占当前内容区 |
| 任务详情内打开附件预览 | 任务详情右侧并排预览 | 挤占任务详情，不将外层聊天改为并排 |
| 创建任务 | 模态弹窗 | 不挤占，不以跳转项目页替代会话入口 |
| 批量添加成员、新建群聊／AI 团队 | 模态弹窗 | 不挤占；使用下述共同拉人形态 |
| 文件信息、身份资料 | 居中弹窗 | 不冒充文件内容预览 |
| 退出／解散等需确认的操作 | 确认弹窗 | 不以一级页面承载确认 |

子区在主会话区域完整打开时仍属于当前会话，不要求任何子区访问都打开侧栏。表格中的“子区侧栏”是附属打开方式。

## 3. 共同外壳与状态边界

- Eva 是桌面客户端。系统标题栏全局唯一且持续可见，业务页面、右侧面板与默认遮罩位于其下方，不重造或遮挡系统标题栏。
- 聊天任务、子区、聊天信息和子区信息共用右侧面板的 56px 标题栏、20px 左右内边距、内容区与右侧关闭位置，不为各入口建立另一套外壳风格。
- 文件预览保持同一套内容工具与全屏能力；全屏仅覆盖系统标题栏下方、最左侧全局导航右侧的工作区，最左导航保留。退出全屏恢复原并排宽度。
- 打开聊天信息不重建聊天流或输入区，保留当前草稿与滚动位置。关闭附属面板后仍回到所属对象，不残留其他会话的内容。
- 一级页面只替换客户端内容区，个人 Eva 和团队 IM 继续保持各自业务形态；布局统一不合并它们的历史或数据。

## 4. 拉人模板 A：两种形态

项目、群聊和 AI 团队共用一套模板 A，由入口配置选择创建形态或纯拉人形态，不维护两套独立选择器。

| 形态 | 适用入口 | 内容与主按钮 |
| --- | --- | --- |
| 创建形态 | 新建项目群／非项目群 | 群聊名称＋双栏选择区；“创建群聊” |
| 创建形态 | 新建自定义 AI 团队 | 团队名称＋双栏选择区；“创建” |
| 纯拉人形态 | 添加项目成员、添加群成员 | 只有双栏选择区；“确认添加” |
| 纯拉人形态 | 编辑自定义 AI 团队成员 | 只有双栏选择区；“保存” |

### 结构与尺寸

- 弹窗宽 680px，双栏左右等分；左侧搜索、候选分组与候选列表，右侧“已选 N”、清空与已选列表。两侧列表分别滚动，标题及页脚固定在列表之外。
- 创建形态从上到下为标题与关闭、名称、双栏选择、实际提交错误、取消与唯一主按钮。名称输入与选择区左边缘对齐，候选少时不压缩成矮弹窗。
- 纯拉人不显示名称、头像字段和外层“成员”标签，不为缺失字段保留左侧空白，双栏占满内容宽度。
- 候选行最小高度 52px，已选行最小高度 40px；两侧头像均为 28px，姓名 14px、单行截断并保留 AI 标。分组用轻量间距和细分隔线，不叠加多层卡片或边框。
- 搜索使用 Search 图标，不显示快捷键提示。分组标题用灰色小字及当前搜索结果数量，空分组不显示；已选为空时显示“从左侧选择成员”。
- 无选择时“清空”禁用；名称或专项最低选择数不满足时主按钮禁用。错误只在发生后显示，不预留错误高度。
- 窄窗口适配仍保留左右候选／已选的双栏语义。弹窗与遮罩位于客户端系统标题栏下方。
- 拉人过程不编辑头像；创建后的群／自定义团队头像管理按专项保留。

### 初始选择与状态

- 创建和普通添加默认空选；编辑 AI 团队按已保存成员快照初始化右栏。
- 搜索只过滤合资格候选，不扩大权限，也不清除已选。点击候选行或复选框可选择；右侧可逐项移除，移除后回到符合条件的候选中，也可清空。
- 取消或关闭后再次打开不保留未提交的名称、搜索、选择及错误；切换目标项目、群、团队或操作者时重新初始化。取消编辑不改变已保存成员。
- 提交事务由专项业务负责：任一候选校验失败不保留部分结果；成功后关闭弹窗并更新目标对象。模板不自行定义成员权限。

### 空状态

| 场景 | 无候选时说明 | 下一步提示 |
| --- | --- | --- |
| 添加项目成员 | 所有可添加成员均已加入项目 | 无 |
| 添加项目群成员 | 项目内可选成员均已加入当前群聊 | 如需添加其他人，请先将其加入项目 |
| 添加非项目群成员 | 所有可选成员均已加入当前群聊 | 无 |
| 新建项目群 | 项目内暂无其他可选成员 | 无 |
| 新建非项目群 | 暂无可选成员 | 无 |
| AI 团队 | 暂无可用的 AI 成员 | 请先创建或接入 AI 成员 |

说明用 13px 灰色正文，下一步用 12px 更浅文字，两行间距 8px。只有输入搜索条件后无结果才显示“没有匹配的成员”，并移除业务空状态的下一步提示。

### 适用边界

- 转让负责人、群主或选择任务负责人属于单人选择，不套用批量拉人模板；带入本人分身属于身份配置，数字员工加入项目属于资源加入。
- 全员群的添加转为项目成员添加；子区不单独拉人，默认 AI 团队不手动维护成员。
- 候选与已选身份遵循[身份展示规范](./联系人与AI身份展示规范.md)。项目／群候选资格与批量事务读[我的项目](../专项规范/我的项目.md)，群聊入口读[我的消息](../专项规范/我的消息.md)，AI 团队最低人数与成员快照读[我的 AI](../专项规范/我的AI.md)。
