# 通用：配色规范

版本：v0.1，2026-09-15。规定颜色的业务含义与跨入口一致性；具体色板由共享设计资源维护，不在各专项另建色值表。

## 1. 颜色职责

| 类别 | 表达内容 | 边界 |
| --- | --- | --- |
| 品牌与操作强调 | Eva 主蓝色、主要动作与提及强调 | 不表示项目身份或成员权限 |
| 状态色 | 未读、危险、任务状态等已有状态 | 不因项目配色改变状态含义 |
| 中性表面与文字 | 页面、列表、普通文字及次级信息 | 不将所有文字与背景染成项目色 |
| 项目色 | 所属项目的稳定视觉身份 | 不代表当前选中、权限高低或任务状态 |

普通 IM 未读数量用中性数字徽标，@我用蓝色强调；我的 AI 的未读圆点使用红色，未读数字仍为中性色。不能因都表示未读而统一改成红底数字。

## 2. 项目色的唯一来源

- 每个项目保存唯一配色标识，所有入口由同一项目数据派生颜色。不按名称猜颜色，不提供用户选色入口。
- 改名、排序、置顶和刷新不改变项目色；新项目按稳定 ID 分配既定色板。
- 不同项目允许复用色系，仍须用名称区分，颜色不充当项目唯一标识。
- 同一色系包含主色、浅底色、边框色，分别用于图标／线条、背景、边框；不通过降低整个头像或图标的透明度冒充浅底色。

## 3. 跨入口规则

| 对象 | 配色规则 |
| --- | --- |
| 项目目录、项目切换、项目归属提示 | 图标读取同一项目主色 |
| 项目页签背景与边框 | 读取同一项目浅底色与边框色 |
| 项目全员群、普通群默认头像 | 继承所属项目色系，不单独保存第二套项目色 |
| 子区 | 从父群解析所属项目，不另配色系 |
| 自定义群头像 | 上传图像优先，不染色、不替换 |
| 非项目群 | 保留独立稳定配色，不伪造默认项目归属 |
| 联系人与其他 AI 头像 | 不随所在项目或群改变 |

项目路径文字保持次级文字色，项目色用于归属图标。正文、任务状态、消息背景仍按各自语义显示。

## 4. 状态与兼容

- 项目切换后所有相关入口同步取色，不能残留上一个项目的颜色。
- 颜色不授予访问权，不能用颜色判断成员资格或治理权限。
- 已有合法项目配色优先保留，旧数据缺色按统一兼容规则补齐，业务页面不能各自猜测。
- 明暗主题如接入，共用同一项目配色标识，由公共色板派生；不能维护两套项目身份映射。本条不表示完整深色模式已实现。
