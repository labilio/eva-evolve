# 需要保留的界面状态

用户切到其他页面再回来，应能接着之前的工作继续。以下状态在切换页面、刷新，以及关闭后重新打开时保留。

适用范围：个人 Eva、我的消息、Agent 的聊天与会话列表，以及任务页的筛选、排序和视图偏好。

| 需要记住什么 | 返回时的表现 |
| --- | --- |
| 未发送的文字 | 输入框保留之前写好的内容，包括换行和提及。每个会话独立保存。 |
| 待发送的附件 | 已添加但未发送的附件继续留在输入区。本轮原型用示例附件演示。 |
| 正在回复的消息 | 输入区保留引用对象，可以接着回复，不重复插入提及。 |
| 输入光标和选中文字 | 保留编辑位置或选中范围，继续输入时不用重新找位置；不自动抢焦点。 |
| 输入框内部的滚动位置 | 长草稿保持原来正在查看的段落。 |
| 当前会话或子区 | 回到上次打开的聊天；主聊天和各子区分别记忆草稿。 |
| 聊天内容的滚动位置 | 正在看历史消息时回到原处；原先在最底部时继续显示最新消息。 |
| 会话列表的滚动位置 | 中栏列表回到原来的位置，不每次跳回顶部。 |
| 分组的展开和收起 | 文件夹、会话分组、AI 身份和小队保留用户上次的展开状态。 |
| 筛选条件 | 保留关注/最近、全部/未读/@我，以及任务页已选的筛选条件。 |
| 排序方式 | 保留任务页选择的排序字段和升序、降序。 |
| 视图模式 | 保留任务页选择的看板、表格或层级视图。 |

保留时遵循以下规则：

- 不同会话、子区和入口各自记忆，内容不串到其他地方。
- 成功发送后，清空本次文字、引用和附件；发送失败时保留。
- 用户主动清空、取消引用或移除附件后，不再自动恢复这些内容。
- 用户主动打开指定会话或跳转某条消息时，优先执行这次操作。
- 已删除或无权访问的会话不恢复，返回可访问的默认位置。
- Mock 只用于首次准备演示内容，不覆盖用户后续修改。

菜单、弹窗、悬停提示、消息多选等临时操作状态不需要记住。本轮不扩展到所有表单；原型中的记忆保留在同一浏览器中，不包含跨设备同步。
