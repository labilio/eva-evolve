# 项目任务选人逻辑速览

> 适用范围：项目任务体系内所有选人入口（创建弹窗、任务详情属性区、任务列表逐项/批量指派）。公共组件为 `AssigneePicker`（`prototype/009-6-patch-general.js` 补丁），候选数据统一由父容器（任务所属项目）推导，禁止入口自取全局名单。

## 1. 三类身份字段的候选范围

| 字段 | 候选范围 | 默认值 | 可清空 |
| --- | --- | --- | --- |
| 执行负责人 | 仅**本项目联系人**（AI 不担任负责人） | 未指派 | 允许（「未指派」项） |
| 来源者 | 手动创建：固定本人不可选；详情改选：全部联系人 + 项目内 AI | 当前操作人 | 不允许（必选） |
| 创建者 | 手动创建：固定本人不可选；详情改选：与来源者一致（不含项目管家） | 当前操作人 | 不允许（必选） |

- 写入校验与候选同源：负责人写入时校验必须在项目 `humans` 内；来源者/创建者经 `evaResolveTaskIdentity` 校验，AI 身份不在项目 `cloneIds`/`employeeIds` 内一律拒绝。
- 项目管家不进入任何任务身份候选。
- 自动化的「执行器 / 发送到」是自动化自身模型（全局专家/专家团），不在本规范内。

## 2. 候选分组

分组按身份类型推导，标题固定：

| 顺序 | 分组标题 | 来源 |
| --- | --- | --- |
| 1 | 联系人 | 通讯录人类（member） |
| 2 | AI 分身 | 项目内分身（clone） |
| 3 | 数字员工 | 项目内数字员工（employee） |

- 分组顺序固定为 `联系人 → AI 分身 → 数字员工`（内部顺序键 `member, clone, employee, agent, squad`）。
- 「联系人」分组内本人（当前操作人 `actorId`）恒排在第一位，其余联系人保持候选原始顺序；检索态仍按相关度排序。
- 当前没有候选的分组不渲染（不显示空分组）。
- 单个分组时仍显示分组标题（与 @提及面板的差异点，曾讨论单分组隐藏标题，当前实现保留标题）。

## 3. 每组展示上限与展开

- 每组默认最多显示 **5 条**，超出显示「展开其余 N 位 / 个」：
  - 人类用「**位**」，AI（分身/数字员工）用「**个**」；
  - 展开只作用于当前分组，面板重开或修改检索词后恢复折叠；
  - 「展开其余」不进入键盘候选序列（↑↓/Enter 不会落在它上面）。
- 面板内容区限高滚动：`min-height: 72px`、`min-width: 220px`（避免检索结果过少时面板骤缩）；`max-height` 在打开时按触发点到「标题栏下沿 / 视口底」的可用空间取 `min(480px, 可用空间)`，内容不足上限时按内容收缩，长列表在限高内滚动。
- 弹层宿主固定在系统标题栏下沿（`.eva-task-popup-host`），Semi 的溢出回弹只在该区域内进行，不会把长列表顶到标题栏上方。

## 4. 搜索框

- **显示条件**：候选总数 **> 5**（即至少有一组需要展开）才显示搜索框；负责人这类短列表（≤5 人）不显示。
- **位置**：面板最顶部（搜索框 → 「未指派」（如显示）→ 分组列表）。
- **匹配规则**：纯名称子串匹配，`NFKC` 归一 + `toLocaleLowerCase()` 后 `includes`；不做拼音/首字母匹配。
- **输入法组词守卫**：组词期间（拼音未上屏）不过滤、不重排；`compositionend` 上屏瞬间以输入框实际内容为准更新检索词（受控 state 不依赖 onChange 的 isComposing 时序）。搜索框为非受控 input，组词拼音不会被轮询 re-render 抹掉。
- **键盘**：↑↓ 在候选间移动、Enter 选择当前项；组词期间 Enter/方向键交给输入法。

## 5. 检索态（有检索词时）

- **单列平铺**：隐藏全部分组标题与「展开其余」，跨全部分组统一取结果。
- **相关度排序（降序）**：名称精确 > 名称前缀 > 名称包含；同级按命中位置更靠前、名称更短、原候选顺序。
- **无结果**：显示空提示「未找到匹配的联系人或 AI」。
- **「未指派」项隐藏**（检索态语义是"找人"，不提供清空操作）；清空检索词后恢复分组视图与「未指派」（如该入口允许清空）。

## 6. 面板行为细节

- 面板打开时重置：检索词清空、展开状态清空、键盘焦点复位（-1）。
- 点击面板内搜索框 / 「展开其余」不会关闭面板（`stopPropagation`）；点击选项后选人并关闭。
- 「未指派」项仅在**允许清空的入口**（负责人类）且**非检索态**显示。
- 候选身份行 = 头像（`EvaAIIdentity.avatar` 公共头像）+ 名称 + AI 标（仅 AI 身份）。
