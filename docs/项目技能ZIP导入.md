# 项目设置：技能 ZIP 导入

创建弹窗只保留「空白起草」「从 ZIP 导入」，沿用现有左右分栏。ZIP 选择、解析结果、名称和描述属于创建组件；关闭或离开页面销毁，异步解析结果不得回写到已关闭的弹窗。切换方式保留各自输入，不互相覆盖。

一次导入一个 ZIP，包含唯一的 SKILL.md；允许包在外层文件夹内。先解析并预览正文与文件，再导入当前项目并打开共用技能编辑器。名称沿用现有英文、数字、连字符和下划线合同。同项目重名必须改名，不覆盖旧技能。导入不绑定专家、不触发执行。

正文与文本附件可以继续编辑，二进制附件原样保留并提供下载；保存文本时不能丢失二进制附件元数据。解析器拒绝损坏包、无效路径、多技能包；20 MB 压缩大小、50 MB 展开大小、500 文件是当前原型的资源上限。

技能仍使用现有浏览器内存中的项目业务数据。切换入口或项目后保留，刷新页面会重置；没有接入云端存储或新增长期文件持久化。

## 验证

- `node --test tests/project-skill-zip.test.mjs`：真实正文、路径与二进制附件、外层文件夹、异常包和资源上限。
- 构建后 `node --test tests/browser/project-skill-zip.mjs`：Edge/Chromium 中选择 ZIP、预览、导入、编辑保存、下载附件、重名、空白起草、入口往返及项目隔离。
