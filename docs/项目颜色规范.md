# 项目颜色规范

本规范适用于项目目录、项目切换、项目页签、消息关注/最近/搜索、群头像及 Eva 项目管理专员身份入口。它约束项目身份配色，不改变全局主题、任务状态色、导航选中色、权限与业务结构。

## 唯一数据源

- 项目记录的 `colorKey` 是项目配色的唯一权威字段。不提供用户选色入口。
- `prototype/004-project-appearance.js` 的 `window.EvaProjectAppearance` 是唯一色板与派生接口。业务组件不得另建色板、手写项目色值或自行混色。
- 新项目按稳定 ID 分配有限色板；改名、排序、置顶、刷新均不改变颜色。不同项目允许复用色系，项目名称必须继续展示，不能只靠颜色辨认项目。
- 预置项目固定映射：`prod` → `blue`（供应链运营协同）、`official` → `violet`（EVA Official Space）、`lab` → `teal`（客户联合交付）、`drive-design` → `sky`（团队文件功能设计）。不得按项目名称猜测映射。
- 旧数据读入时通过项目适配器迁移；已有合法 colorKey 优先，预置项目无 colorKey 时使用当前预置映射，其他旧项目匹配历史色板或按 ID 回退。保存项目时去除派生的 color/colorBg，只保存 colorKey。历史迁移脚本中的旧色值仅用于兼容，不得用于当前展示。

## 色彩语义

每个项目使用一个色系，包含三个用途不同的不透明颜色，不能通过对整个图标或头像设置 opacity 代替。

| 语义 | 用途 |
| --- | --- |
| `accent` 主色 | 项目图标、默认群头像的线条 |
| `surface` 浅底色 | 默认群头像、项目管理专员头像、项目页签栏渐变起始色 |
| `border` 边框色 | 默认群头像外圈、项目页签栏底部分隔线 |

正文、页签文字、任务状态及消息背景沿用原有语义颜色。项目页签保留现有渐变、尺寸和布局，不因接入项目配色改变信息层级。

## 入口合同

| 入口 | 规则 |
| --- | --- |
| 项目目录、置顶项目卡片 | 项目图标用 accent，图标底色用 surface |
| 项目切换按钮及下拉选项 | 名称前展示对应项目图标，图标用 accent；切换后随当前项目同步更新 |
| 项目页签背景及分隔线 | 与当前项目图标共用项目数据，分别取 surface、border |
| 消息关注分类 | 项目分类右侧跳转按钮展示同色项目图标，左侧不重复展示图标并与非项目分类对齐；非项目分类不伪造项目归属 |
| 最近、跨项目搜索、聊天顶部 | 项目归属图标用 accent，路径文字仍使用次级文字色 |
| 项目全员群、普通群的默认头像 | 继承所属项目的 accent/surface/border，不保存群级项目颜色副本 |
| 子区 | 通过父群解析项目，不独立分配项目色系 |
| 自定义群头像 | 优先保留上传图像，不染色、不替换 |
| 非项目群 | 保留独立稳定配色，不套用默认项目颜色 |
| Eva 项目管理专员 | 有项目归属时头像底色用 surface，保留机器人图案；无归属时保留现状。成员、消息、身份卡共用公共身份组件 |
| 人类与其他 AI | 不因所在群或项目改变身份头像 |

项目图标使用既有 Lucide 语义，禁止手写 SVG 或另造项目图形。AI 头像继续调用 `EvaAIIdentity.avatar`，项目管理专员由 `projectAgentAppearance` 提供外观，不得在业务入口单独加背景补丁。

## 状态与接口

- `normalize(project)`：生成用于存储的项目记录。
- `view(project)`：为现有组件派生兼容的 color/colorBg 字段；这些字段不是第二份权威状态。
- `get(project, theme)`：返回 colorKey、accent、surface、border；theme 支持 light/dark。
- `css(project)`：返回随 CSS color-scheme 切换的颜色表达式。
- 项目页签颜色由 React 当前项目对象直接推导，不再由 DOM 脚本读取标题、按名称查询 localStorage 或覆盖颜色。
- 群所属项目与可访问性由成员数据仓库解析。颜色不用于判定权限，也不授予访问权。
- 切换项目时重新推导颜色；退出页面不保留额外颜色状态。禁止用 Observer、定时器或 DOM class 维护第二套项目配色状态。

## 明暗主题

明暗模式共用 colorKey，由公共色板派生各自颜色，不新增第二套项目映射。主题接入须统一设置客户端 color-scheme；数据 URI 群头像可传 theme，默认读取客户端 color-scheme，主题变化后需经组件正常重渲染更新。提供明暗取色接口不代表完整深色模式已验收。

## 置顶表现

初始默认置顶全部四个预置项目：供应链运营协同、团队文件功能设计、EVA Official Space、客户联合交付；保留用户已经手动保存的选择，不在刷新时强制补回。已置顶图钉内部填充 currentColor，未置顶空心，并同步 aria-pressed。置顶状态不能靠项目色表达；置顶与消息关注关系继续遵循《消息关注与项目置顶》。

## 修改与验收

新增项目颜色入口前先读本规范，复用公共接口。修改色板或公共取色逻辑时，检查上述全部入口，不仅检查当前页面。

至少验证：预置映射、旧数据兼容、改名/刷新稳定、新项目取色、项目与父群/子区一致、自定义头像保留、无项目回退、项目专员有归属/无归属差异，以及项目切换往返。执行 `tests/project-appearance.test.mjs` 和项目要求的相关测试、构建及合同检查。

视觉验收必须使用真实浏览器，核对项目图标、头像背景、页签背景和边框属于同一色系，并检查切换后的更新。静态检查或构建通过不能代替浏览器验收；用户禁止测试时遵从并明确说明未验收。
