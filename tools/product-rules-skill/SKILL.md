# Eva 产品规范

本包是 Eva 产品规则的可移植快照，供研发与规则评审使用。无需原型仓库、专用工具或外部服务。只读取与当前请求相关的规范；不要默认加载全部文档。

## 使用方式

1. 根据任务对象从下表选择通用规范和菜单专项。跨菜单功能再读取文内引用的业务所有者规则。
2. 以文档中明确的规则、范围和例外约束当前工作；不把实现方式、素材提及或菜单名称当成新增能力要求。
3. 本轮用户明确的新决定优先于快照。发现冲突时说明涉及的具体条款；只对影响当前工作的缺失产品决定询问，继续完成不依赖它的内容。
4. 规则未覆盖的功能不代表被禁止或已授权；按现有项目要求处理，不从已有代码、历史测试或原型方案自行推导 Eva 产品政策。
5. 输出说明实际引用的规范、已落实的规则和仍未确定的事项。不要将“符合文档”表述为真实服务已接通或全部功能已验收。
